## 摘要
我们通过实验和系统级仿真表明，通过电路级补偿技术和算法级的批量归一化重新校准，可以成功缓解保留损失对推理精度下降的影响。实验是在标准65 nm CMOS工艺制造的单多晶浮栅（FG）模拟非易失性存储器阵列上进行的，用于模拟内存计算。我们使用经实验校准的保留损失统计模型来评估对神经网络模型（如VGG-10/CIFAR-10和WideResNet-28-10/CIFAR-100）的系统级影响。我们表明，在编程后60天，组合缓解技术能够将基线推理精度恢复在2-4%以内。

## Abstract
We show with experiments and system-level simulations that it is possible to successfully mitigate the impact of retention loss on inference accuracy degradation by using both circuit-level compensation techniques and batch normalization recalibration at the algorithmic level. Experiments are performed on a single-poly floating-gate (FG) analog non-volatile memory array for analog in-memory computing fabricated in a standard 65 nm CMOS. We use a model of retention-loss statistics calibrated with experiments to evaluate the system-level impact on neural network models such as VGG-10/CIFAR-10 and WideResNet-28-10/CIFAR-100. We show that, after 60 days since programming, combined mitigation techniques enable to recover the baseline inference accuracy within 2-4%

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：在基于单多晶浮栅（Single-Poly Floating-Gate）的模拟内存计算（Analog In-Memory Computing, AIMC）芯片中，编程后浮栅电荷泄漏（retention loss）会导致存储的权重电流发生漂移，从而严重降低神经网络推理精度。与数字存储器不同，模拟存储器中每个多级状态直接对应突触权重，电荷泄漏会直接扰动矩阵-向量乘法运算。
- **研究背景**：AIMC通过避免冯·诺依曼瓶颈并利用亚阈值操作实现高能效。浮栅存储器凭借成熟的CMOS工艺、无需额外掩模、内在多级可编程性等优势被广泛研究，但其保留损失问题成为部署障碍。现有工作多针对温度补偿，而针对保留时间退化的系统性缓解方案尚不充分。
- **整体含义**：本文旨在通过**电路级**（自适应读取电压补偿）与**算法级**（批量归一化重新校准）的协同作用，在实际硬件上验证保留损失对推理精度的影响可被有效抑制，为浮栅AIMC芯片的长寿命可靠部署提供可行路径。

### 关键技术细节
- **实验保留模型提取**：基于TSMC 65 nm单多晶浮栅阵列（1T-1FG结构，W/L=240nm/180nm）在室温下存放10、30、60天后的电流漂移测量。
  - 对电流在log‑log坐标进行线性拟合：`log10(Ii) = m·log10(IPi) + q + χ`
    - `IPi` 为编程电流，`Ii` 为保留后电流。
    - `m`、`q` 为确定性漂移参数（与保留时间相关）。
    - `χ ~ N(0, σ²(I(t0)))` 为零均值正态随机变量，标准差 `σ` 也随时间和编程电流变化（图2g）。
  - 进一步定义 `V1n`（读取电流达1 nA所需Vread），其漂移的标准差与平均漂移呈正比例（图2f）。
- **Vread补偿（VRC）**：通过增大读取电压 `Vread` 抵消平均电流增长，将编程电流与保留后电流的对应关系拉回原直线。
- **批量归一化重新校准（BNR）**：利用校准数据集重新估算硬件映射后各BN层的输出均值和方差，更新BN层的统计参数，从而补偿随机权重漂移造成的激活分布偏移。
- **权重映射方案**：采用差分阵列实现有符号权重，正负权重各映射到独立阵列，列电流在模拟前端相减。软件权重 `Wi` 映射到编程电流 `IPi`：
  ```
  IPi = (|Wi| / Wmax) * (Imax - Imin) + Imin
  ```
  其中 `Imin=0.4 nA, Imax=80 nA`。输入激活量化为7比特。
- **仿真框架**：硬件感知的推理仿真，将保留模型注入到网络推理中，评估四种配置：无缓解（NM）、仅VRC、仅BNR、VRC+BNR。
