## 摘要
模拟存内计算（CIM）能够实现高能效的神经网络推理，但器件变化和读出噪声会严重降低低比特量化模型的性能。现有的面向CIM的量化方法主要最小化理想量化误差，忽略了硬件噪声基底，从而导致精度分配效率低下。我们提出了NANQ，一种面向模拟CIM的噪声感知混合精度非均匀量化框架。NANQ根据eFlash CIM阵列的实测响应来建模与幅值相关的权重噪声，并将噪声分布转换为自适应量化密度，在低噪声区域分配更细的精度，同时避免在噪声主导区域浪费无效精度。它进一步通过统一阈值识别各层在硬件噪声下的精度饱和点，从而分配逐层位宽。在eFlash CIM SoC上的芯片实验表明，在2比特权重幅值量化下，与PowerQuant相比，NANQ将视觉模型准确率平均提高8.05个百分点，并将语言模型困惑度（PPL）平均降低54.7%。混合精度NANQ仅用3.2-3.8等效比特即可捕获通过额外量化资源所获得的绝大部分收益。

## Abstract
Analog compute-in-memory (CIM) enables energy-efficient neural network inference, but device variation and read noise can severely degrade low-bit quantized models. Existing CIM-oriented quantization methods mainly minimize ideal quantization error, ignoring the hardware noise floor and thus causing inefficient precision allocation. We propose NANQ, a noise-aware mixed-precision non-uniform quantization framework for analog CIM. NANQ models magnitude-dependent weight noise from measured responses of an eFlash CIM array and converts the noise profile into an adaptive quantization density, assigning finer resolution to low-noise regions while avoiding ineffective precision in noise-dominated regions. It further assigns layer-wise bit-widths by identifying each layer's precision saturation point under hardware noise using a unified threshold. On-chip experiments on an eFlash CIM SoC show that, under 2-bit weight-magnitude quantization, NANQ improves vision-model accuracy by 8.05 percentage points and reduces language-model PPL by 54.7% on average over PowerQuant. Mixed-precision NANQ captures most of the gains obtainable from additional quantization resources with only 3.2-3.8 equivalent bits.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：模拟存内计算（Analog Compute-in-Memory, CIM）通过将神经网络权重存储在存储单元中、利用模拟域矩阵向量乘法实现高能效、高并行度的推理加速。然而，实际器件存在**工艺偏差、热噪声、读噪声、非线性和编程随机性**等非理想因素，导致映射到CIM阵列的实际权重偏离期望值，严重损害低比特量化模型的精度。
- **核心问题**：
  1. 现有面向CIM的量化方法（如均匀量化、PowerQuant等）主要优化**理想量化误差**，忽视硬件噪声基底（noise floor）。
  2. 随着比特数增加，量化误差降低到硬件噪声水平以下后，继续增加分辨率的收益迅速饱和——即“精度饱和效应”，导致位宽资源在噪声主导区域被浪费。
  3. 不同网络层在硬件噪声下达到精度饱和的速率差异显著，统一位宽分配会造成资源的次优配置。
- **论文含义**：需要一种**直接感知硬件噪声特性**的量化框架，将有限的量化精度分配到真正受益的区域和层上，从而在低比特条件下最大化模拟CIM的推理性能。

## 2. 方法论：NANQ框架

### 2.1 核心思想

NANQ将实测的**与权重幅值相关的硬件噪声分布σ(w)**转化为**非均匀量化密度ρ(w)**，使低噪声区域获得更细的量化间隔，噪声主导区域分配较宽的间隔；同时通过识别每层的“精度饱和点”来自动分配逐层位宽，实现**无需重训练、无需组合搜索**的混合精度量化。

### 2.2 关键技术细节与公式

- **总误差分解**（公式2-4）：权重区域w的总体误差方差近似为量化误差方差与硬件噪声方差之和：σ²_tot(b,w) = σ²_q(b,w) + σ²_h(w)。量化误差近似正比于2^(-2b)，硬件噪声项固定；当量化误差远低于硬件噪声时，SNR趋近于平台，继续增加比特不再带来有效收益。
- **逆噪声密度函数**（公式5）：ρ(w) = 1/(σ(w)+ε)^γ。其中γ控制噪声适应的强度（γ=0退化为均匀量化），ε确保数值稳定性。低噪声区域密度高、间隔窄；高噪声区域密度低、间隔宽。
- **CDF等分构造量化边界**（公式6-8）：对ρ(w)积分得到累积密度F(w)，将[0, F(w_max)]均分为Q份，反解出量化边界{e_i}，重建层取相邻边界中点。此构造直接利用噪声分布形状，无需迭代优化。
- **噪声感知的混合精度分配**（公式9-12）：对每层l，在其他层保持全精度的情况下，用不同候选位宽b和不同γ值施加NANQ量化并注入实测噪声，记录最小硬件感知损失E_l(b)；用单调递减曲线拟合后，定义可恢复损失降低比例R_l(b)，通过统一阈值τ选择该层位宽b*_l = min{b | R_l(b) ≤ τ}。
- **等效平均位宽**（公式13）：使用权重数量加权平均，得到Beq用于衡量资源开销。

## 6. 主要结论与发现

- 在Bm=2低比特场景下，NANQ相对PowerQuant：视觉模型Top-1准确率平均提升**8.05个百分点**（VGG-11提升高达24.41pp），语言模型PPL平均降低**54.7%**（最高达73.3%）。
- 在Bm=3~4时优势仍显著；随着位宽升高（5~6比特），差距缩小，说明噪声感知级别分配在低比特（噪声主导）时收益最大。
- 混合精度NANQ用**仅3.2~3.8等效比特**捕获了绝大多数可行增益，在所有对比模型上均优于同预算的APoT、PowerQuant和PNMQ混合精度方案。
- γ的最优选取在低比特时（Bm=2）至关重要（偏差±0.2导致PPL从294升至393），高比特时敏感性显著降低。
- τ=0.1提供了性能与资源的最佳折衷（过多降低τ带来的额外精度收益有限）。
