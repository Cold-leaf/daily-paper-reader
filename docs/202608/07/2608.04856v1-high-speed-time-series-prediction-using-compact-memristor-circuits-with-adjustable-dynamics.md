## 摘要
利用Ta$_2$O$_5$非易失性忆阻器作为紧凑、可追踪且易于控制的动态储备池计算层，执行时间序列预测任务。利用其强烈依赖电压的开关速度进行信息处理，使得能够根据正负驱动电压脉冲配置可调的编程和遗忘时间。在时间序列预测问题上对此框架进行基准测试表明，可配置的遗忘动态能够使用相当少的忆阻输入通道实现高预测精度。训练可以基于固定遗忘时间下使用线性回归优化输出层，也可以同时优化遗忘时间。在第一种情况下，使用六个忆阻通道；在第二种情况下，仅使用两个忆阻通道即可为基准任务展示出色的预测精度。该方案允许工作频率跨越多个数量级进行调谐：通过调整输入电压电平，同一忆阻动态层的信息处理速度可以从kHz范围提升至MHz范围，同时保持出色的预测精度。这些发现证明了基于忆阻器的动态网络在快速时间信号的分析、预测和恢复方面的优势，接近电信数据速率。

## Abstract
Ta$_2$O$_5$ nonvolatile memristors are used as compact, traceable, and well-controllable dynamic reservoir computing layers to perform time-series prediction tasks. The strongly voltage-dependent switching speed is utilized for information processing. It enables the configuration of tailorable programming and forgetting times in response to the positive and negative driving voltage pulses. Benchmarking this framework on time-series prediction problems reveals that the configurable forgetting dynamics enables a high prediction accuracy using a rather small number of memristive input channels. The training is based either on optimizing the output layer using linear regression with fixed forgetting times, or on optimizing the forgetting times as well. In the first case, six memristive channels, while in the second, only two memristive channels are used to demonstrate excellent prediction accuracy for the benchmark tasks. This scheme allows for the tunability of the operating frequency over many orders of magnitude: by adjusting the input voltage levels, the information processing speed of the same memristive dynamic layer can be increased from the kHz to the MHz range while maintaining excellent prediction accuracy. These findings demonstrate the merits of memristor based dynamic networks in the analysis, prediction and recovery of fast temporal signals, approaching telecommunication data rates.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- 用**非易失性忆阻器的动态响应**替代传统储层中大量节点的复杂度，即“以动态复杂度替代网络复杂度”。
- 输入信息编码为正脉冲幅度，负向偏置电压实现可控“遗忘”，通过调节偏置水平即可独立配置每个通道的记忆时间尺度。

### 2.2 核心物理基础：时间-电压困境
- 忆阻器开关时间与偏压呈指数关系（式4）：
  \[
  \tau = 10^{-(|V_{bias}| - B)/A}
  \]
- 本工作所用Ta₂O₅器件参数：A=0.0415，B=1.42。文献中同类器件的趋势线跨越约15个数量级时间域，超快实验已证明可达皮秒级开关时间。

### 2.3 驱动方案（关键创新）
- 每个通道由“忆阻器+串联电阻（1kΩ）”构成。
- 编程：正电压脉冲，幅度与输入u(k)成线性关系（Vin=a·u(k)+b，其中a=1V, b=0.5V）。
- 遗忘：脉冲间隔期间施加恒定的负向偏置电压（V_offset,i），每个通道可独立设置。
- 读取：每个编程脉冲后跟一个0.1V的小读取脉冲，测量串联电阻上的分压V_out,i(k)作为通道状态。
- 所有段（编程、读取、负偏置）在kHz实验中时长1 ms，在MHz实验中时长1 μs。

### 2.4 输出层与训练方式
- 输出为各通道输出电压的线性组合（含偏置项w₀）：
  \[
  y_{predicted}(k) = w_0 + \sum_i V_{out,i}(k) \cdot w_i
  \]
- 训练采用**线性回归**优化权重wi（软件中计算），误差指标为归一化均方误差（NMSE）。

### 2.5 三种信息处理方式（Approach I / II / III）
- **方法I**：用6个忆阻通道，每个通道固定不同的负向偏置电压（−1.0 V至−1.5 V，步长−0.1 V），只训练输出层权重。
- **方法II**：仅用2个忆阻通道，训练时同时优化输出权重和两个通道的偏置电压（在6×6=36种偏移组合中搜索最佳）。
- **方法III**：研究通道数N从少到多时的预测精度，通道和偏移电压均为**随机选择**，每个N测试100次随机组合，评估方案的鲁棒性与可扩展性。

### 2.6 频率加速方案
- 通过将脉冲长度从1 ms缩短至1 μs，并同步将编程与偏移脉冲幅度各增大0.2 V（偏移范围调整为−1.2 V至−1.7 V），实现从kHz到MHz三个数量级的提速。
- 高速测量采用50 Ω阻抗匹配电路和跨阻放大器（Femto DHPCA，200 MHz带宽）。
