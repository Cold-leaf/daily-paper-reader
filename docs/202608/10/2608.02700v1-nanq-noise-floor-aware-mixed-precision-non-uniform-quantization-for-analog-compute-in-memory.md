## 摘要
模拟存内计算（CIM）能够实现高能效的神经网络推理，但器件变异和读出噪声会严重降低低位量化模型的性能。现有面向CIM的量化方法主要最小化理想量化误差，忽略了硬件噪声基底，导致精度分配效率低下。我们提出NANQ，一种面向模拟CIM的噪声感知混合精度非均匀量化框架。NANQ从eFlash CIM阵列的实测响应中建模与幅值相关的权重噪声，并将噪声分布转换为自适应量化密度，为低噪声区域分配更精细的分辨率，同时避免在噪声主导区域浪费无效精度。它进一步通过统一阈值识别各层在硬件噪声下的精度饱和点，从而分配逐层位宽。在eFlash CIM SoC上的芯片实验表明，在2位权重量化下，与PowerQuant相比，NANQ将视觉模型准确率平均提高8.05个百分点，语言模型困惑度平均降低54.7%。混合精度NANQ仅需3.2-3.8等效位即可获得额外量化资源的大部分收益。

## Abstract
Analog compute-in-memory (CIM) enables energy-efficient neural network inference, but device variation and read noise can severely degrade low-bit quantized models. Existing CIM-oriented quantization methods mainly minimize ideal quantization error, ignoring the hardware noise floor and thus causing inefficient precision allocation. We propose NANQ, a noise-aware mixed-precision non-uniform quantization framework for analog CIM. NANQ models magnitude-dependent weight noise from measured responses of an eFlash CIM array and converts the noise profile into an adaptive quantization density, assigning finer resolution to low-noise regions while avoiding ineffective precision in noise-dominated regions. It further assigns layer-wise bit-widths by identifying each layer's precision saturation point under hardware noise using a unified threshold. On-chip experiments on an eFlash CIM SoC show that, under 2-bit weight-magnitude quantization, NANQ improves vision-model accuracy by 8.05 percentage points and reduces language-model PPL by 54.7% on average over PowerQuant. Mixed-precision NANQ captures most of the gains obtainable from additional quantization resources with only 3.2-3.8 equivalent bits.

- **背景**：深度神经网络（DNN）计算量与复杂度持续增长，推动了对高能效推理加速器的需求。模拟存内计算（Analog Compute-in-Memory, CIM）凭借在存储阵列内原位计算的能力，在能效和计算密度上相较传统数字处理器具有显著优势。
- **核心问题**：模拟CIM面临器件工艺偏差、热噪声、非线性等非理想特性（non-idealities），导致权重编程后的实际值与期望值存在偏差，严重时会使低位宽（low-bit）量化模型精度大幅退化。已有CIM量化方法主要聚焦于**最小化理想量化误差**（如最小化权重域重构误差），而未将硬件噪声基底（noise floor）纳入量化设计考量，由此导致量化精度在不同权重区域、不同网络层之间的分配效率低下。
- **整体含义**：本文主张量化设计应**以硬件噪声特性为先导**——量化分辨率应集中分布在噪声较小的权重区域，位宽分配应止步于硬件噪声已使精度收益饱和的层级，从而以极低的等效比特数获得接近更大量化资源下的精度收益。

### 二、论文提出的方法论

#### 1. 核心思想

NANQ将**芯片实测的幅值相关权重噪声分布**（magnitude-dependent noise profile）转化为**自适应量化密度**（adaptive quantization density），对噪声小的权重区域分配更精细的量化级，噪声主导区域则避免无效的精度消耗；同时给出**逐层位宽分配策略**，识别各层在硬件噪声下的精度饱和位宽。

#### 2. 理论分析

- 权重区域 w 附近的总体误差方差近似为：
  \[
  \sigma^2_{\text{tot}}(b,w) = \sigma^2_q(b,w) + \sigma^2_h(w)
  \]
  其中 \(\sigma^2_q(b,w)\) 为量化误差方差，\(\sigma^2_h(w)\) 为硬件噪声方差。
- 量化误差随位宽 b 按指数规律下降：\(\sigma^2_q(b,w) \propto 2^{-2b}\)。
- 当 \(\sigma^2_q \ll \sigma^2_h\) 时，信噪比趋于上限 \(\text{SNR} \to P_{\text{sig}}(w)/\sigma^2_h(w)\)，继续增加位宽不再带来有效改善；由此产生“精度饱和”效应。

#### 3. 非均匀量化算法：噪声感知密度与CDF划分

- 从eFlash CIM阵列的重复读取测量中提取噪声强度函数 \(\sigma(w)\)（不限定具体解析形式，泛化性好）。
- 定义**逆量化密度函数**：
  \[
  \rho(w) = \frac{1}{(\sigma(w)+\epsilon)^\gamma}
  \]
  其中 \(\gamma \ge 0\) 控制噪声适配强度，\(\epsilon>0\) 保证数值稳定性。
- 通过累计密度划分构造量化边界：
  \[
  F(w) = \int_0^w \rho(u)\,du,\quad F(e_i) = \frac{i}{Q}F(w_{\max})
  \]
  得到分层边界 \(\{e_i\}\) 后，重构级取区间中点，符号位独立处理。
- 该方法无需重训练，不依赖显式迭代边界优化，只需一次噪声表征和少量推理试验，即可生成噪声自适应的量化间隔。

#### 4. 混合精度分配策略

- 对每层 l，在候选位宽集合 \(B = \{b_{\min},\dots,b_{\max}\}\) 上进行NANQ量化并注入实际噪声，其他层保持全精度，得到硬件感知损失 \(E_l(b)\)。
- 对损失曲线拟合单调非增趋势 \(\tilde{E}_l(b)\)，定义**可恢复损失残差比例**：
  \[
  R_l(b) = \frac{\tilde{E}_l(b) - \tilde{E}_l(b_{\max})}{\tilde{E}_l(b_{\min}) - \tilde{E}_l(b_{\max}) + \epsilon}
  \]
- 给定统一阈值 \(\tau\)，选取：
  \[
  b^*_l(\tau) = \min\{b \in B \mid R_l(b) \le \tau\}
  \]
  该过程避免了网格搜索或组合优化；最终在少量候选 \(\tau\) 上评估端到端性能并选定阈值。

### 六、论文的主要结论与发现

- NANQ在45组模型–位宽配置中的38组上取得最佳量化结果，优势在低比特（2–3 bit）下尤为突出：
  - 在 \(B_m = 2\) 时，ResNet-20、VGG-11、ViT-Base准确率分别较PowerQuant提高7.21、24.41、1.22个百分点；语言模型PPL最高降低73.3%。
  - 在 \(B_m = 3\) 时，PPL较PowerQuant降低1.5%–20.5%，较小模型受益更明显。
- 混合精度NANQ在匹配预算下对所有测试模型取得最优：等效位宽仅3.2–3.8 bit；
  - 相比Mixed PowerQuant，视觉模型准确率提升2.23–2.52个百分点，语言模型PPL降低3.8%–9.9%。
- 消融实验表明：γ在极低位宽下影响显著（\(B_m=2\) 时PPL可从294增至393），高位宽下稳健（退化 < 0.5%）；τ = 0.1为精度与开销之间的合适平衡点。

### 七、优点

1. **硬件噪声感知的量化密度设计**：将实测量化噪声直接映射到量化器设计，而非停留在理想误差最小化，概念清晰且实用性强。
2. **免训练、低开销**：无重训练、无迭代边界优化，仅需少量推理试验，适合部署场景。
3. **良好的通用性**：噪声强度函数不依赖特定解析模型，可适配不同模拟存储器技术。
4. **真实芯片验证**：基于eFlash CIM SoC实测，而非纯仿真，结果可信度高。
5. **直击应用痛点**：在低比特（2–3位）下优势显著，而这一区间恰是模拟CIM实际部署面临最大挑战的场景。
6. **混合精度机制简洁高效**：用统一阈值 + 归一化残差比例即可完成逐层位宽决策，避免了复杂搜索/组合优化。

### 八、不足与局限

1. **噪声模型范围有限**：仅对幅值相关的权重噪声建模，未考虑激活噪声、读出放大电路噪声、输入转换非线性、阵列行/列间的系统性偏差等；部分更复杂的噪声可经校准部分缓解，但未纳入框架。
2. **等效位宽为算法级指标**：\(B_{\text{eq}}\) 不直接等于物理存储/延迟/能耗收益，实际增益需硬件映射与编译器配合，论文对此未展开。
3. **依赖硬件特性标定**：温度、老化、工作条件显著变化时噪声分布可能漂移，需更新σ(w)；论文未给出该类场景下的鲁棒性数据。
4. **实验覆盖有限**：未在RRAM、MRAM等其他主流CIM技术上进行验证；混合精度实验仅给出部分模型的对比，未系统分析τ大范围扫描下的精度–位宽前沿。
