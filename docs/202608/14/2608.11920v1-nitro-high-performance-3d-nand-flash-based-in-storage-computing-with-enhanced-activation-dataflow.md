## 摘要
存储内计算（ISC）被认为是一种下一代内存架构，因为它能够缓解主机与内存之间的数据瓶颈。近年来，大型语言模型（LLM）所需的资源显著增加，但内存密度并未相应扩展。最近，一些工作研究了基于NAND闪存的存内处理（NAND-PIM）方案，以利用内存的高密度。然而，它们没有解决中间值的数据流/缓冲区问题，因此一种简单的方法是在慢速闪存阵列中处理这些值。为了克服这一限制，我们提出了一种基于NAND闪存的高性能ISC架构，具有增强的激活缓冲。我们的架构不使用非常慢的闪存阵列来存储中间值，而是将值缓冲在快速的DRAM子系统中。这种方法有效处理了当激活被编程到较慢的TLC NAND闪存时的高延迟惩罚。我们还为NAND-PIM阵列引入了一种分布式数据流方法。该方法通过高效的平面内数据映射最大限度地提高了计算并行性。结果表明，我们提出的架构实现了显著的性能改进，与基线相比，推理延迟降低了高达85%。

## Abstract
In-storage computing (ISC) is considered a next-generation memory architecture for its ability to relieve the data bottleneck between the host and the memory. While the required resources of large language models (LLMs) have increased significantly in recent years, the memory density has not scaled accordingly. Recently, several works have studied NAND flash-based processing-in-memory (NAND-PIM) schemes to exploit the high density of the memory. However, they do not address the dataflow/buffer for the intermediate values, so a simple method is to deal with the values in the slow flash memory array. To overcome such a limitation, we propose a high-performance NAND flash-based ISC architecture with enhanced activation buffering. Instead of using the very slow flash memory array for the intermediate values, our architecture buffers the values in a fast DRAM subsystem. This approach effectively handles the high-latency penalties when activations are programmed into slower TLC NAND flash. We also introduce a distributed dataflow approach for the NAND-PIM array. This approach maximizes computational parallelism by employing efficient intra-plane data mapping. The results show that our proposed architecture achieves significant performance improvements, reducing the inference latency by up to 85% compared to the baseline.

## 1. 论文的核心问题与整体含义

- **研究动机**：Transformer 大语言模型参数规模激增，导致主机与内存之间的数据搬运成为严重性能瓶颈；同时，传统 DRAM/SRAM/ReRAM PIM 方案在存储密度和可扩展性上难以匹配 LLM 的容量需求。
- **核心问题**：3D NAND 闪存具有超高存储密度、非易失性和低成本等优势，天然适合做存储内计算（ISC/PIM）。但现有 NAND-PIM 方案（如 3D-FPIM、S-FLASH）主要聚焦于矩阵向量乘（MVM）本身，**忽视了中间激活值的数据流管理与缓冲问题**：若中间激活需要写回 NAND 阵列，TLC 闪存极其缓慢的编程/读取延迟（数百微秒至毫秒级）会严重拖累整体推理性能。
- **整体含义**：论文提出 NITRO 架构，通过“DRAM 缓冲中间激活 + 分布式数据流”结合异构 PIM（NAND-PIM + DRAM-PIM），在 SSD 内部实现高性能 LLM 推理加速，为闪存计算存储提供了新的数据流优化思路。

## 2. 论文提出的方法论

- **核心思想**：不将所有 Transformer 计算都放在 NAND-PIM 上，而是根据计算特征将线性层（权重密集型）映射到 TLC NAND-PIM，将注意力层（激活-激活密集）及中间激活缓冲映射到快速 DRAM（或 pSLC 模式），从而避开 TLC 慢速编程/读取。
- **激活 DRAM 缓冲（Activation DRAM Buffering）**：
  - 中间激活（例如 K 矩阵）不再编程进 NAND 闪存，而是以极低延迟写入 DRAM；注意力计算（QK^T、SV）转用 DRAM-PIM 完成。
  - 避免了 TLC NAND 编程（~1ms）带来的流水线空转，大幅降低注意力阶段延迟。
  - 针对无 DRAM 的 SSD，采用 pSLC 模式作为替代，但实验表明 pSLC 仍慢于 DRAM，仅作为备选。
- **分布式数据流（Distributed Dataflow）**：
  - 线性层：权重矩阵垂直切分并分布到多个物理平面（Plane），激活矩阵水平切分，在不同平面上并行执行 MVM，减少迭代次数；利用 NAND 多平面并行性，部分输出直接拼接得到完整结果。
  - 注意力层：在 DRAM-PIM 中，多个注意力头分布在独立 bank 上并行计算；在 pSLC NAND-PIM 中，多头 K 矩阵采用对角分布方式映射到不同 BL 组，Q 逐行输入，受限于电流累加精度，同一次迭代只能处理少量头（如 i 个头），SV 计算因 token 方向点积较长、可并行头数更少（如 2 个头）。
- **NITRO 硬件架构**：
  - SSD 控制器管理 NAND 子系统与 DRAM 子系统；DRAM 子系统采用 McDRAM 风格 PIM bank 处理注意力/激活函数。
  - NAND 闪存 die 内集成 BLS 解码器、ADC（带积分器/电容）、处理元件（PE）用于数字累加；保留旁路路径以支持传统闪存读/编程操作。
  - 权重量化（INT8）按符号-幅值表示：7 位幅值拆成 3 部分存到多个 TLC 单元；正权重存偶数 BL、负权重存奇数 BL；激活按位串行输入，通过差分电流感应完成 MVM，PE 内移位累加得到最终结果（最高 16 位）。

## 6. 论文的主要结论与发现

- 与 3D-FPIM baseline 相比，完整 NITRO（DRAM 缓冲 + 分布式数据流）平均降低推理延迟约 99.7%（最高），吞吐量提升约 287 倍；与 S-FLASH 相比，延迟降低最多约 93.1%，吞吐量提升约 14.5 倍。
- DRAM 缓冲的效果显著优于 pSLC：虽然 pSLC 比 TLC 快，但其多比特数据按页排布导致 ADC 复用/外设开销增大，无法抵消单元级速度增益，因此 DRAM 是激活缓冲的首选。
- 分布式数据流进一步优化了线性层的执行效率，通过多平面并行和垂直/水平切分提升了 NAND-PIM 阵列利用率。
- 能量方面，相比 3D-FPIM 降低约 98.9%；相比 S-FLASH 降低平均约 72.6%。

## 7. 优点

- **系统级数据流视角**：针对 NAND-PIM 只关注 MVM 内核的局限性，系统性地处理了中间激活的读写瓶颈，提出了“线性层放 TLC，注意力层放 DRAM”的异构 PIM 映射策略。
- **可落地的硬件设计**：给出了完整的 SSD 内 NITRO 架构，包括 BLS 解码器、ADC、PE、旁路路径、DRAM-PIM bank 等细节，并分析了面积/能量/吞吐的 tradeoff。
- **实验对比丰富**：同时对比了 3D-FPIM 和 S-FLASH 两条典型路线，并做了配置消融和 DRAM/pSLC 两种缓冲介质的比较，结论可信度较高。
- **设计具有可扩展性**：支持不同权重精度（INT4/8/16）和多种 Transformer 模型，对 NAND 平面/层数变化也有一定适应能力。
