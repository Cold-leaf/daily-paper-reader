## 摘要
存储内计算（ISC）因其能够缓解主机与存储器之间的数据瓶颈而被视为下一代存储器架构。近年来，大型语言模型（LLM）所需的资源显著增加，但存储器密度并未相应扩展。近期，一些研究工作探索了基于NAND闪存的存储内处理（NAND-PIM）方案，以利用存储器的高密度优势。然而，这些方案未能解决中间值的数据流/缓冲问题，因此简单的方法是在慢速闪存阵列中处理这些值。为克服这一限制，我们提出了一种具有增强激活缓冲功能的高性能NAND闪存ISC架构。我们的架构将中间值缓冲在快速DRAM子系统中，而不是在非常慢的闪存阵列中处理。这种方法有效处理了将激活值编程到较慢的TLC NAND闪存时产生的高延迟开销。我们还为NAND-PIM阵列引入了一种分布式数据流方法。该方法通过高效的平面内数据映射最大化计算并行性。结果表明，我们提出的架构实现了显著的性能提升，与基线相比，推理延迟最多降低了85%。

## Abstract
In-storage computing (ISC) is considered a next-generation memory architecture for its ability to relieve the data bottleneck between the host and the memory. While the required resources of large language models (LLMs) have increased significantly in recent years, the memory density has not scaled accordingly. Recently, several works have studied NAND flash-based processing-in-memory (NAND-PIM) schemes to exploit the high density of the memory. However, they do not address the dataflow/buffer for the intermediate values, so a simple method is to deal with the values in the slow flash memory array. To overcome such a limitation, we propose a high-performance NAND flash-based ISC architecture with enhanced activation buffering. Instead of using the very slow flash memory array for the intermediate values, our architecture buffers the values in a fast DRAM subsystem. This approach effectively handles the high-latency penalties when activations are programmed into slower TLC NAND flash. We also introduce a distributed dataflow approach for the NAND-PIM array. This approach maximizes computational parallelism by employing efficient intra-plane data mapping. The results show that our proposed architecture achieves significant performance improvements, reducing the inference latency by up to 85% compared to the baseline.

# NITRO 论文总结

## 1. 核心问题与整体含义

- **研究背景**：Transformer 大语言模型（LLM）规模快速增长，参数量呈指数级膨胀，而内存密度未同步提升，导致主机与存储之间的数据搬运成为严重性能瓶颈，推理延迟增加且算力利用率低下。
- **现有方案不足**：存内计算（PIM）是缓解该瓶颈的候选方向，但 DRAM/SRAM/ReRAM 类 PIM 受限于密度和扩展性；3D NAND 闪存具有高存储密度、非易失性、低每比特成本等优势，因此 NAND-PIM 受到关注。
- **关键差距**：已有 NAND-PIM 工作（如 3D-FPIM、S-FLASH）主要聚焦于矩阵向量乘（MVM）内核本身，使用简化配置（小阵列、SLC），且**忽略了中间激活值的数据流与缓冲问题**。当 LLM 推理中产生的中间激活需要写回慢速 TLC NAND 阵列时，编程延迟（数百微秒级）成为严重瓶颈。
- **论文含义**：提出 NITRO，一种面向 Transformer 的 3D NAND 闪存 ISC/PIM 架构，通过"快速 DRAM 缓冲中间激活 + 分布式数据流"两个核心策略，显著降低 LLM 推理延迟、提升吞吐并降低能耗，使 NAND-PIM 真正可用于复杂 LLM 工作负载。

## 2. 方法论

**整体架构（混合异构 PIM）**
- 将工作负载按数据访问特征映射到不同的 PIM 子系统：
  - **线性层（Q/K/V 投影、O 投影、FFN）→ TLC NAND-PIM**：涉及大矩阵权重 × 激活，权重可静态存储在 TLC 大容量阵列中，编程不影响推理。
  - **注意力层（QKT、SV）→ DRAM-PIM**：涉及激活 × 激活的中间矩阵乘法，避免将中间矩阵编程到慢速 TLC NAND。
  - 无 DRAM 的 SSD 配置下，可用 **pSLC 模式 NAND** 作为替代缓冲/计算介质。

**关键技术 1：激活 DRAM 缓冲（Activation DRAM Buffering）**
- 中间激活（如 K0）从 NAND-PIM 产出后快速写入 DRAM 缓冲，再转置后用于注意力计算。
- 避免了将 KT 编程到 TLC NAND 所需的数百微秒延迟，DRAM 读写仅需约 50–100 ns。
- 缓解了基线中的流水线停顿问题：无需等待 KT 编程完成即可开始 QKT 计算，降低了资源争用和空闲时间。

**关键技术 2：分布式数据流（Distributed Dataflow）**
- **线性层**：
  - 权重矩阵**垂直划分**（按列切分 W0、W1）并分发到不同平面，配合激活矩阵**水平划分**（A0、A1），实现多平面并行 MVM，输出部分结果直接拼接。
  - 解码阶段输入为单向量时，广播至多个平面生成部分和，仍能利用多平面并行。
  - 相比顺序 tiling（每次只能算一小块），大幅减少迭代次数。
- **注意力层（DRAM-PIM 场景）**：多头注意力分布到不同 DRAM bank，利用 bank 级并行按向量方式计算各头 QKT。
- **注意力层（pSLC 场景）**：多头 K 矩阵以对角线方式映射到不同 BL 组；Q 按行输入。QKT 的点积方向是向量方向，单次可并发较多头；而 SV 点积沿 token 方向，单次并发头数受限，需更多迭代。

**计算细节**
- 权重采用 INT8 符号-幅值表示：7 位幅值补零成 9 位，分成三部分存入多个物理 TLC cell，按页面方向分布；正权重存偶 BL，负权重存奇 BL。
- 激活以 2 的补码位串行输入，BLS decoder 按位激活 NAND 串；差分 BL 电流经整合器/电容后由 ADC 数字化。
- PE 对 ADC 结果做移位累加，跨输入位累加部分积，最终 16 位输出拆分为两个 8 位部分存入 data/cache 寄存器。

## 3. 实验设计

**基准方法**
- **3D-FPIM**：代表基于 TLC NAND 的模拟电流求和的 PIM，权重按 128×128 子矩阵平铺。
- **S-FLASH**：利用激活/权重的位级稀疏性、低精度 SA，权重按 512×128 平铺，受限于 ADC 分辨率需额外迭代。
- 对比三种配置：**BL**（基线）、**BL+AB**（NITRO 激活缓冲，DRAM 或 pSLC）、**BL+AB+DD**（完整 NITRO，激活缓冲 + 分布式数据流）。

**工作负载**

## 6. 主要结论与发现

- **激活 DRAM 缓冲显著降低延迟**：相比 3D-FPIM 基线平均加速 4.07×，主要原因是消除了中间激活回写 TLC NAND 的高延迟编程操作。
- **DRAM 优于 pSLC**：pSLC 编程虽快于 TLC，但页级多位数据布局（每字节至少 7 对 BL）会增加 ADC 多路复用延迟，抵消单元级速度收益。
- **完整 NITRO（DRAM 场景）**：归一化延迟低至 0.003（相对 3D-FPIM）和 0.069（相对 S-FLASH）；pSLC 场景下分别为约 0.29 和 0.448。
- **吞吐提升显著**：相对 3D-FPIM 约 287×，相对 S-FLASH 约 14.5×。
- **能耗大幅下降**：相对 3D-FPIM 平均减少约 98.9%，相对 S-FLASH 约 72.6%；pSLC 场景略高于 DRAM 但仍优于基线。
- **面积开销主要体现在 NAND 外设的 16-bit ADC**：NAND-PIM 每平面总面积为 46.66 mm²（其中 ADC 17.51 mm²），DRAM-PIM 每 bank 约 7.08 mm²。
