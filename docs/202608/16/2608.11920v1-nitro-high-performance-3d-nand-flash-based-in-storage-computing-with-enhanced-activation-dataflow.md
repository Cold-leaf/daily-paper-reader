## 摘要
存储内计算（ISC）被认为是一种下一代内存架构，因为它能够缓解主机与内存之间的数据瓶颈。尽管近年来大型语言模型（LLM）所需的资源显著增加，但内存密度并未相应扩展。最近，一些工作研究了基于NAND闪存的存内处理（NAND-PIM）方案，以利用内存的高密度。然而，它们没有解决中间值的数据流/缓冲区问题，因此简单的方法是在慢速闪存阵列中处理这些值。为了克服这一限制，我们提出了一种高性能的基于NAND闪存的ISC架构，具有增强的激活缓冲。我们的架构不是为中间值使用非常慢的闪存阵列，而是将值缓冲在快速DRAM子系统中。这种方法有效处理了激活编程到较慢的TLC NAND闪存时的高延迟惩罚。我们还为NAND-PIM阵列引入了一种分布式数据流方法。这种方法通过采用高效的平面内数据映射来最大化计算并行性。结果表明，我们提出的架构实现了显著的性能提升，与基线相比，推理延迟降低了85%。

## Abstract
In-storage computing (ISC) is considered a next-generation memory architecture for its ability to relieve the data bottleneck between the host and the memory. While the required resources of large language models (LLMs) have increased significantly in recent years, the memory density has not scaled accordingly. Recently, several works have studied NAND flash-based processing-in-memory (NAND-PIM) schemes to exploit the high density of the memory. However, they do not address the dataflow/buffer for the intermediate values, so a simple method is to deal with the values in the slow flash memory array. To overcome such a limitation, we propose a high-performance NAND flash-based ISC architecture with enhanced activation buffering. Instead of using the very slow flash memory array for the intermediate values, our architecture buffers the values in a fast DRAM subsystem. This approach effectively handles the high-latency penalties when activations are programmed into slower TLC NAND flash. We also introduce a distributed dataflow approach for the NAND-PIM array. This approach maximizes computational parallelism by employing efficient intra-plane data mapping. The results show that our proposed architecture achieves significant performance improvements, reducing the inference latency by up to 85% compared to the baseline.

### 一、论文的核心问题与整体含义（研究动机和背景）

- **背景**：Transformer 架构的 LLM 参数规模急剧膨胀，导致内存容量和带宽成为推理性能的关键瓶颈。主机与存储之间频繁的数据搬运带来了严重的“内存墙”问题。存储内计算（ISC）和存内处理（PIM）被视为缓解这一瓶颈的下一代内存架构方案。
- **NAND-PIM 的潜力**：3D NAND 闪存具有极高的存储密度、非易失性和低成本等优势，非常适合存储 LLM 的大规模权重参数；同时其阵列结构天然支持基于模拟电流累加方式的矩阵向量乘（MVM）运算，因此基于 NAND 闪存的 PIM（NAND-PIM）方案受到关注。
- **现有方案的缺陷**：
  - 已有的模拟域 NAND-PIM 方案（如 3D-FPIM、S-FLASH）大多聚焦于 MVM 算子本身的优化，未针对 LLM 推理过程中大量中间激活值（如 Q、K、V 矩阵及其乘积）的存储与数据流进行系统设计。
  - 面对 LLM 中注意力机制（Attention）所需的激活矩阵乘激活的运算（如 QKᵀ、SV），中间数据必须一次性编程写入 TLC NAND 单元。而 TLC 的编程延迟高达数百微秒甚至约 1,000μs，会严重拖慢整体推理流水线，造成大量空闲等待时间。
- **核心问题**：如何在保留 NAND 高密度存储优势的同时，规避慢速闪存处理中间激活值的延迟惩罚，实现高性能的 LLM 存储内推理？

### 二、论文提出的方法论（核心思想与关键技术细节）

论文提出了 **NITRO** 架构，核心思路是：**TLC NAND-PIM 负责权重密集型计算（线性层），DRAM（或 pSLC）-PIM 负责激活密集型和频繁读写型计算（注意力层）**，并对 NAND-PIM 的数据映射与调度进行分布式优化。

1. **激活 DRAM 缓冲（Activation DRAM Buffering）**
   - 传统方案中，中间激活值（如 K 矩阵）需要编程到 TLC NAND 才能进行后续的 QKᵀ 乘法，编程延迟极大。
   - NITRO 引入异构混合 PIM 架构：线性层（QKV 线性投影、O 线性投影、FFN 层）本质是静态权重矩阵与激活的矩阵乘，映射到高密度 TLC NAND-PIM 执行，一次写入后推理时无需重新编程权重。
   - 注意力层（QKᵀ、SV）激活与激活乘法频繁，若在 NAND 中计算需反复编程中间值。NITRO 将其卸载到 DRAM-PIM（基于 McDRAM/LPDDR4 架构）中，DRAM 的读/写延迟仅约 50–100ns，比 TLC 编程快约三个数量级，从而大幅减少 Attention 计算延迟。
   - 无 DRAM 的 SSD 场景下，可用 pSLC（伪单层单元）模式代替；pSLC 编程速度比 TLC 快但依然远慢于 DRAM，故实验中将 DRAM 与 pSLC 两种情形分别讨论。

2. **分布式数据流（Distributed Dataflow）**
   - **线性层（TLC NAND-PIM）的优化**：
     - 利用 3D NAND 多平面（Plane）并行的特性，将权重矩阵 W 进行**垂直划分**（按行拆分）后分布到不同平面上，激活矩阵按行水平划分，使各平面同时计算部分输出，通过拼接得到最终结果，避免资源闲置。
     - 推理 prefill 阶段激活矩阵有多个 token 行，将 A 水平划分为 A₀ 与 A₁，分别送入不同平面与不同权重组相乘，实现 token 级并行；decode 阶段将输入向量广播到各平面。
   - **注意力层（DRAM-PIM 或 pSLC）的优化**：
     - DRAM-PIM 场景：将多个注意力头分配到不同 DRAM Bank，利用 Bank 级并行独立计算各头的 QKᵀ 与 SV。
     - pSLC 场景：采用对角分布方式将多个头的 K 矩阵分布于不同 BL 组，Q 按行输入进行乘累加；由于 SV 计算按 token 维度做点积，单个 chunk 较大，可并行处理的 V 头数受限（如 2 个头），需要多轮迭代。

3. **硬件实现细节（NITRO 架构）**
   - NAND-PIM 平面集成 BLS 解码器（按输入激活位激活 NAND 串）、ADC（含积分器和负载电容，16-bit SAR-ADC，每 6 条 BL 共享 1 个）、PE（处理单元，做移位与累加）。
   - 权重以 INT8 符号-幅值格式存储：7-bit 幅值前补 2 个 0 形成 9-bit，拆分存于多个物理单元；正权重存偶数 BL、负权重存奇数 BL，通过差分电流实现有符号 MVM。
   - 输入激活按位串行送入，PE 按位重建部分积并移位累加，最终输出可拆分为两个 8-bit 部分经数据/缓存寄存器送出。

### 六、论文的主要结论与发现

- **延迟**：完整 NITRO（DRAM 缓冲 + 分布式数据流）相比 3D-FPIM 基线，归一化延迟降至约 **0.003**，即推理延迟降低 **最高 99.7%**；相比 S-FLASH 基线降至约 **0.069**，降低约 **93.1%**。
- **吞吐量**：与 3D-FPIM 基线相比，吞吐量提升约 **287×**；与 S-FLASH 基线相比提升约 **14.5×**。
- **能耗**：相比 3D-FPIM 基线，平均能耗降低约 **98.9%**；相比 S-FLASH 基线平均降低约 **72.6%**。其中 pSLC 方案能量略高于 DRAM 方案但差距小于 1%。
- **DRAM vs pSLC**：DRAM 是激活缓冲的更优介质；pSLC 虽比 TLC 快，但按页多比特布局增加了 ADC 多路复用延迟，抵消了部分单元级提速。
- **分布式数据流收益显著**：通过多平面并行、垂直权重划分、多 token 并行、多头并行，大幅压缩线性层 MVM 的迭代次数。
- **面积**：NAND-PIM 单平面面积约 46.66mm²，其中高分辨率 ADC 占 17.51mm²（约 37.5%），为高并行计算付出的面积代价显著；DRAM-PIM 单 Bank 面积约 7.08mm²。

### 七、优点（方法与实验设计亮点）

1. **问题定位精准**：明确指出现有 NAND-PIM 在 LLM 推理中的核心瓶颈是中间激活值在慢速 NAND 上的编程延迟，而非 MVM 计算本身。
2. **异构 PIM 分工合理**：将权重密集型线性层放在高密度 TLC NAND-PIM，将激活密集型注意力层放在低延迟 DRAM-PIM，发挥各自存储介质特性，思路清晰、系统性强。
3. **分布式数据流设计细致**：不仅考虑平面级并行，还细粒度地针对线性层与注意力层分别设计了垂直/水平划分和对角头分布方案，并考虑了 prefill 与 decode 阶段的不同并行策略。
4. **工程可实现性较好**：硬件设计具体到 BLS 解码器、ADC 精度与数量、PE 移位累加逻辑、正负差分 BL 结构等；利用已有商用存储规格（YMTC 256Gb TLC、Micron LPDDR4）与成熟 PIM 研究（McDRAM）作为参数依据。
5. **实验矩阵丰富**：涵盖 6 种模型、2 个基线、多种配置与 4 类指标，并给出面积分解，分析较全面。

### 八、不足与局限

1. **缺少实际硬件验证**：全部结果来自仿真模型，论文也未进行流片或基于真实 3D NAND 器件的实测，模拟结果与实际电路行为之间可能存在偏差。
2. **面积代价高**：为了精确数字化模拟 MVM 结果，NAND-PIM 外设中 ADC 面积占比很高（37.5%）；并未比较该面积开销下相对成本收益的替代方案（如更低精度 ADC 配合纠错/补偿）。
3. **pSLC 场景收益有限**：在无 DRAM 的 SSD 中，pSLC 方案即使加分布式数据流，相对 3D-FPIM 的延迟归一化值约为 0.29，远不如 DRAM 方案的 0.003，实用性讨论不够深入。
4. **未评估模型精度**：论文明确省略了精度评估，只是假设单元变化与之前研究一致。INT8 量化下 NAND 模拟计算的精度损失缺乏数据支撑，特别是在多层累加后的误差累积方面。
5. **对比公平性可提升**：基线（3D-FPIM、S-FLASH）未经过与 NITRO 相同级别的数据流优化，且原方案面向更简单的 DNN，直接将其扩展到大型 Transformer 可能使其性能处于劣势。
6. **未覆盖编码器模型或更大规模模型**：工作负载以 decoder-only 的 LLaMa/OPT 为主，未讨论 T5/BERT 等 encoder 架构或超过 13B 的更大模型，通用性有限。
7. **未讨论端到端系统开销**：未明确计入主机与 SSD 之间 PCIe 通信、模型加载、权重编程时间，以及 Softmax/LayerNorm 等非线性算子在哪一硬件上执行及其代价。
