## 摘要
存内计算（ISC）被认为是一种下一代内存架构，因为它能够缓解主机与内存之间的数据瓶颈。虽然近年来大型语言模型（LLM）所需的资源显著增加，但内存密度并未相应扩展。最近，一些工作研究了基于NAND闪存的存内计算（NAND-PIM）方案，以利用内存的高密度优势。然而，这些方案并未处理中间值的数据流/缓冲区，因此一种简单的方法是在慢速闪存阵列中处理这些值。为了克服这一限制，我们提出了一种具有增强激活缓冲功能的高性能NAND闪存ISC架构。我们的架构将中间值缓冲在快速DRAM子系统中，而不是使用非常慢的闪存阵列。这种方法有效处理了将激活值编程到较慢的TLC NAND闪存时的高延迟惩罚。我们还为NAND-PIM阵列引入了一种分布式数据流方法。该方法通过高效的面内数据映射最大化计算并行性。结果表明，我们提出的架构实现了显著的性能改进，与基线相比，推理延迟降低了高达85%。

## Abstract
In-storage computing (ISC) is considered a next-generation memory architecture for its ability to relieve the data bottleneck between the host and the memory. While the required resources of large language models (LLMs) have increased significantly in recent years, the memory density has not scaled accordingly. Recently, several works have studied NAND flash-based processing-in-memory (NAND-PIM) schemes to exploit the high density of the memory. However, they do not address the dataflow/buffer for the intermediate values, so a simple method is to deal with the values in the slow flash memory array. To overcome such a limitation, we propose a high-performance NAND flash-based ISC architecture with enhanced activation buffering. Instead of using the very slow flash memory array for the intermediate values, our architecture buffers the values in a fast DRAM subsystem. This approach effectively handles the high-latency penalties when activations are programmed into slower TLC NAND flash. We also introduce a distributed dataflow approach for the NAND-PIM array. This approach maximizes computational parallelism by employing efficient intra-plane data mapping. The results show that our proposed architecture achieves significant performance improvements, reducing the inference latency by up to 85% compared to the baseline.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于 Transformer 的大语言模型（LLM）参数规模指数级增长，而内存密度与带宽并未同步扩展，导致处理器与内存之间频繁的数据搬运形成严重的内存瓶颈（memory bottleneck），显著增加推理延迟并浪费计算资源。
- **现有方案不足**：
  - 存内计算（PIM）被认为是缓解数据瓶颈的可行方向，先前已有 DRAM、SRAM、ReRAM 等 PIM 方案，但面对 LLM 的庞大规模，需要更高密度、更低成本的存储技术。
  - 3D NAND 闪存因存储密度高、非易失、单位比特成本低而成为候选，衍生出两条路径：SSD 内计算（ISC）和 NAND 存内计算（NAND-PIM）。
  - 已有模拟域 NAND-PIM 工作（如 3D-FPIM、S-FLASH）大多只聚焦 MVM（矩阵-向量乘）内核本身，采用简化设计（小阵列、SLC），且**未处理推理中间激活值（intermediate activations）的数据流与缓冲问题**。若将中间值直接写入慢速 TLC NAND 阵列，数百微秒的 program 延迟将成为严重瓶颈。
- **核心问题**：如何在真实商用 3D NAND 闪存配置下，设计一套能高效管理 LLM 推理中间激活数据流的 NAND-PIM/ISC 架构。
- **整体含义**：本文提出 NITRO，一个采用混合 PIM（NAND-PIM + DRAM-PIM）的 3D NAND 闪存 ISC 架构，通过激活 DRAM 缓冲和分布式数据流，大幅降低 LLM 推理延迟，为 NAND 基存内计算提供了更系统化的数据流解决方案。

## 2. 方法论：核心思想与技术细节

### 核心思想
将 Transformer 推理中的计算块按数据访问特征映射到最合适的 PIM 子系统：
- **线性层（Linear Blocks）**：权重静态且体量大 → 映射到 TLC NAND-PIM，利用高密度存储权重；
- **注意力层（Attention Blocks）**：涉及大量「激活×激活」乘法（如 QKᵀ、SV）→ 映射到快速 DRAM-PIM，避免将中间激活编程进慢速 TLC 闪存；DRAM-less SSD 配置下可用 pSLC 模式替代。

### 关键技术细节 1：激活 DRAM 缓冲（Activation DRAM Buffering）
- 基线方案中，QKᵀ 计算需要先将 Kᵀ 编程进 NAND 单元，TLC program 时间高达数百微秒，造成流水线停顿和空闲。
- NITRO 将中间激活（如 K、Q、V）快速写入 DRAM 缓冲，并将注意力计算卸载至 DRAM-PIM；DRAM 读写延迟（~50–100 ns）比 TLC NAND 读写（20–1000 μs）快 3–4 个数量级。
- 注意 QKᵀ 与 SV 的计算特征不同：QKᵀ 沿向量维度做点积（分块小，可并行处理多头）；SV 沿 token 维度做点积（分块大，单次迭代可并行的 head 数受限）。
- 对无 DRAM 的 SSD，可用 pSLC 模式替代，但其编程仍明显慢于 DRAM，效果次之。

### 关键技术细节 2：分布式数据流（Distributed Dataflow）
- **线性块**：
  - 权重矩阵（W）转置后做**垂直切分**（W0、W1），分布到不同 plane，配合 BL 方向的电流累加特性，输出部分矩阵可直接拼接；
  - prefill 阶段将激活矩阵（A）**水平切分**（A0、A1）并行送入多个 plane，减少迭代次数；decode 阶段单向量广播到多个 plane 生成部分和；
  - 充分利用 3D NAND 的 **multi-plane 并行性**；权重行维度超出 WL 容量时再考虑水平切分。
- **注意力块**：
  - DRAM-PIM 场景：不同注意力 head 分布到不同 DRAM bank，实现 bank 级并行；
  - pSLC 场景：多 head 的 Kᵀ 采用「对角放置」映射到不同 BL 组，Q 通过 BLS 解码器逐行输入；但同一 BL 上若累加两个以上不同 head 的电流则输出无法保证，因此单次迭代只能处理部分 head。

### 硬件架构
- 顶层为类似商用 SSD 的结构：SSD 控制器管理 NAND 子系统与 DRAM 子系统（DRAM 同时承担映射表、中间数据缓冲和 PIM 计算）。
- NAND die 内含 4 个独立 plane，集成：BLS 解码器（按输入激活激活 NAND 串）、带积分器/电容的 ADC（将模拟计算结果数字化）、处理单元 PE（数字累加）、以及旁路路径（支持常规 NAND 读写）。
- 权重采用 INT8 符号-幅值（sign-and-magnitude）表示：7 位幅值前补 2 个 0 成 9 位，拆成三段存入多个物理单元；正权重存偶数 BL、负权重存奇数 BL；输入激活按 2 的补码位串行（bit-serial）处理，通过差分传感（偶数 BL 充电、奇数 BL 放电）实现有符号模拟 MVM；PE 将 MSB/CSB/LSB 部分积移位累加，最终结果（最高 16 位）拆成两个 8 位部分存入 data/cache 寄存器。

## 6. 主要结论与发现

- **延迟**：完整 NITRO（DRAM 缓冲 + 分布式数据流）相对 3D-FPIM 基线最高降低 **99.7%**（平均约 4.07× 加速）；相对 S-FLASH 基线降低约 **93.1%**。pSLC 方案不如 DRAM（归一化延迟约 0.29 vs 0.003）。
- **吞吐量**：相对 3D-FPIM 提高约 **287×**，相对 S-FLASH 提高约 **14.5×**，得益于 TLC 线性层并行与跨 plane 数据分布。
- **能耗**：相对 3D-FPIM 平均降低约 **98.9%**；相对 S-FLASH 平均降低约 **72.6%**。注意力阶段（QKᵀ、SV）是基线能耗主要来源，卸载到 DRAM 后显著下降；pSLC 场景能耗仅比 TLC 基线略增（<1%），分布式数据流可进一步优化外设利用率。
- **关键洞察**：
  - DRAM 比 pSLC 更适合激活缓冲——pSLC 虽然单元读写更快，但页式多比特数据布局（每字节至少 7 对 BL）增加了 ADC 复用延迟，抵消了单元级速度优势；
  - 注意力块应卸载到 DRAM-PIM，线性块留在 TLC NAND-PIM，此映射是延迟降低的核心；
  - 权重垂直切分 + 激活水平切分 + 多平面并行是线性块吞吐提升的关键。

- **总结**：NITRO 面向 3D NAND 存内计算在 Transformer LLM 推理场景下的数据流瓶颈，提出“线性层 → TLC NAND-PIM、注意力层 → DRAM-PIM”的混合映射策略，并结合激活 DRAM 缓冲与跨 plane/跨 bank 的分布式数据流设计，实现相对 3D-FPIM 约 4.07× 延迟加速、283× 吞吐提升与 98.9% 能耗降低。其核心贡献不在于发明新的单元结构，而在于揭示了“中间激活值不应被编程进慢速 NAND”这一关键设计原则，并为 ISC 架构中异构 PIM 子系统间的协同提供了系统化方案。
- **展望**：未来工作可从以下方向展开：
  - **精度验证**：在真实 NAND 阵列或高精度仿真模型上量化单元噪声对 INT8 推理精度的影响，探索自适应 ADC 量化或冗余编码方案；
  - **硬件原型**：借助商用 3D NAND 开发套件或先进工艺流片验证旁路路径与 ADC 复用逻辑的可行性；
  - **更广负载覆盖**：扩展到 MoE（混合专家）模型、长上下文场景（如 128K token）下的 KV-cache 管理，与多 batch 并发调度；
  - **与其他 PIM 技术融合**：研究 NAND-PIM 与 SRAM/ReRAM-PIM 的能效边界，形成更全面的异构 PIM 设计空间探索框架；
  - **可靠性增强**：将磨损均衡、坏块管理、ECC 集成进 PIM 控制路径，提升其商用 SSD 场景的实用性。
