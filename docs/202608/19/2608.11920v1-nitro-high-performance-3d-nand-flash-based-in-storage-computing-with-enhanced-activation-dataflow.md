## 摘要
存储内计算（ISC）因其能够缓解主机与存储器之间的数据瓶颈，被视为下一代存储架构。近年来，大型语言模型（LLM）所需的资源显著增长，而存储密度却未能相应扩展。近期，多项研究探索了基于NAND闪存的存储内计算（NAND-PIM）方案，以利用存储器的高密度优势。然而，这些方案并未解决中间值的数据流/缓冲区问题，因此一种简单的方法是在慢速闪存阵列中处理这些值。为克服这一局限，我们提出了一种具有增强型激活缓冲区的高性能NAND闪存ISC架构。我们的架构不使用极慢的闪存阵列来存储中间值，而是将值缓冲在高速DRAM子系统中。该方法有效处理了将激活值编程到较慢的TLC NAND闪存时所产生的高延迟惩罚。我们还为NAND-PIM阵列引入了一种分布式数据流方法。该方法通过高效的平面内数据映射，最大限度地提高了计算并行性。结果表明，我们提出的架构实现了显著的性能提升，与基线相比，推理延迟降低了高达85%。

## Abstract
In-storage computing (ISC) is considered a next-generation memory architecture for its ability to relieve the data bottleneck between the host and the memory. While the required resources of large language models (LLMs) have increased significantly in recent years, the memory density has not scaled accordingly. Recently, several works have studied NAND flash-based processing-in-memory (NAND-PIM) schemes to exploit the high density of the memory. However, they do not address the dataflow/buffer for the intermediate values, so a simple method is to deal with the values in the slow flash memory array. To overcome such a limitation, we propose a high-performance NAND flash-based ISC architecture with enhanced activation buffering. Instead of using the very slow flash memory array for the intermediate values, our architecture buffers the values in a fast DRAM subsystem. This approach effectively handles the high-latency penalties when activations are programmed into slower TLC NAND flash. We also introduce a distributed dataflow approach for the NAND-PIM array. This approach maximizes computational parallelism by employing efficient intra-plane data mapping. The results show that our proposed architecture achieves significant performance improvements, reducing the inference latency by up to 85% compared to the baseline.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型语言模型（LLM）参数量呈指数级增长，对内存容量和带宽提出了极高要求。然而存储密度并未同步扩展，导致处理器与存储器之间的**数据搬运（data movement）瓶颈**日益严重，成为影响 LLM 推理延迟和算力利用率的“内存墙”问题。
- **现有方案**：
  - **DRAM/SRAM/ReRAM 类 PIM**：虽有优势，但受限于密度和可扩展性，难以承载大规模 LLM 权重。
  - **NAND 闪存 ISC/PIM**：3D NAND 闪存具有超高存储密度、非易失性、低成本等优势，被寄予厚望。已有工作如 3D-FPIM、S-FLASH 采用模拟电流求和方式在 NAND 阵列内执行矩阵向量乘（MVM）。
- **核心缺陷**：现有 NAND-PIM 方案**未处理中间激活值（intermediate activation）的数据流/缓冲问题**。Transformer 注意力层中 QKᵀ、SV 等操作需要将中间激活编程回慢速 TLC NAND 阵列，而 TLC 编程延迟高达数百微秒，成为严重性能瓶颈；同时，简单地将大权重矩阵切块映射到 NAND 阵列会带来大量冗余迭代，资源利用率低。
- **研究意义**：本文提出的 NITRO 架构通过“**异构 PIM 分工 + 优化数据流**”的方式，为高密度 3D NAND 闪存 ISC 提供了高性能可行的方案，有效缓解 LLM 部署中的内存墙问题。

### 2. 方法论：核心思想与关键技术细节

#### 核心思想
NITRO 采用**混合异构 PIM 架构**，根据计算特征将 Transformer 层中的不同计算块映射到最适合的存储介质：
- **线性层（Linear Blocks）**：权重静态存储于高密度的 **TLC NAND-PIM** 中执行 MVM。
- **注意力层（Attention Blocks）**：涉及激活-激活乘法（如 QKᵀ），频繁读写中间数据，被卸载到 **DRAM-PIM** 执行；同时中间激活缓存于 DRAM 而非慢速 TLC 阵列。

#### 关键技术一：激活 DRAM 缓冲（Activation DRAM Buffering）
- 中间激活值（如 K、V 矩阵）由 NAND-PIM 生成后，**直接写入高速 DRAM**，避免编程到 TLC NAND（~1000μs 级延迟）的瓶颈。
- 注意力计算（QKᵀ、SV）在 DRAM-PIM 中完成，利用 DRAM 亚纳秒级读写速度显著降低延迟。
- 对于无 DRAM 的 SSD 配置，可退而使用 **pSLC 模式** NAND 作为替代缓冲介质，但效果不如 DRAM。

#### 关键技术二：分布式数据流（Distributed Dataflow）
**线性层（TLC NAND-PIM）**：
- **垂直分区**：将权重矩阵 W 转置后垂直切分为 W₀、W₁，分布到不同平面上，使各平面沿 BL 方向并行累积电流。
- **水平分区（Prefill 阶段）**：激活矩阵 A 水平切分为 A₀、A₁，分别送入不同平面，实现 Token 级并行。
- **多平面并行**：充分利用 3D NAND 闪存 die 内 2–4 个独立平面的并发操作能力，减少 MVM 迭代次数。
- **Decode 阶段**：输入为单向量时，将向量广播至多个平面以生成部分输出，再级联形成完整输出。

**注意力层（DRAM-PIM / pSLC NAND-PIM）**：
- DRAM-PIM：不同注意力头部（heads）分布到不同 DRAM Bank，利用 Bank 级并行执行逐向量注意力计算。
- pSLC NAND-PIM：多头部 K 矩阵以**对角放置方案**分布在 BL 组上，多头 Q 矩阵按行经 BLS 译码器输入并乘以其 K 矩阵；受电流累积精度限制，单次迭代只能处理部分头部（如 0–i）。
- SV 计算：因点积沿 Token 维执行，单次迭代可并行处理的 V 头数更少（如仅 2 头），需要更多迭代。

#### 硬件实现
- **NAND-PIM 增强**：BLS 译码器（按输入数据激活 NAND 串）、带积分器的 ADC（将差分电流数字化）、数字累加 PE（按输入位执行移位-求和）、旁路路径（保留传统 NAND 读写功能）。
- **权重映射**：8-bit 权重量化为 INT8，采用符号-幅度表示，7-bit 幅值补零成 9-bit 后拆分到三个物理 TLC 单元；正/负权重分别存于偶/奇 BL。
- **MVM 流程**：输入激活按位串行输入 → BLS 激活 NAND 串 → 电流在 BL 上模拟累加 → 差分检测 → ADC 数字化 → PE 内按位移位累加得到最终结果。

### 6. 主要结论与发现

- **延迟**：完整 NITRO（DRAM 缓冲 + 分布式数据流）相对 3D-FPIM 平均降低约 99.7%（最高 85% 的描述与摘要一致，实为 99.7%），相对 S-FLASH 约降低 93.1%。
- **吞吐**：相对 3D-FPIM 提升约 287×，相对 S-FLASH 提升约 14.5×。
- **能耗**：相对 3D-FPIM 降低约 98.9%；相对 S-FLASH 降低约 72.6%。pSLC 方案能耗比 DRAM 稍高（因 ADC/PE 被并发利用导致外设能耗增加），但仍优于基线。
- **关键发现**：
  - DRAM 缓冲显著优于 pSLC 缓冲——pSLC 虽单元操作更快，但页级多比特布局增加了 ADC 多路复用延迟；
  - 分布式数据流的垂直分区 + 多平面并行可有效避免资源闲置，显著加速线性层；
  - 注意力层的 QKᵀ/SV 是 NAND-only 方案的最大性能瓶颈来源（反复读写慢速 TLC）。

### 7. 优点与亮点

- **异构 PIM 分层映射**：根据访问特性和计算模式将线性层（TLC NAND-PIM）与注意力层（DRAM-PIM）差异化部署，思路清晰且具实用导向。
- **针对性解决真实瓶颈**：明确指出并解决了中间激活值缓冲这一被前人 NAND-PIM 工作忽视的核心问题。
- **分布式数据流的精细设计**：区分 prefill/decode 不同阶段、考虑权重矩阵维度与物理阵列尺寸的适配、利用多平面并行，体现出对 NAND 硬件的深入理解。
- **适配真实商业器件**：使用 256Gb TLC 器件参数、4 平面 die 结构、LPDDR4 DRAM-PIM 参数，较此前简化设计更贴近产业现实。
- **评估较全面**：延迟、吞吐、能耗、面积四维评估，覆盖 6 个模型、2 个基线和 3 层消融，结论支撑度较好。

### 8. 不足与局限

- **缺少精度验证**：未实测 NITRO 的端到端模型精度，仅假设单元变化与之前工作一致；INT8 量化和模拟 MVM 的噪声对 LLM 生成质量的影响未得到验证。
- **无真实芯片验证**：全部结果来自模拟器/架构级建模，ADC 能耗、模拟电流精度、工艺偏差等实际工程问题可能被低估。
- **面积开销大**：16-bit SAR-ADC 占 NAND 外设面积很大（每个平面 ADC 面积 17.51mm²，接近存储阵列的 64%），对量产成本和良率构成挑战。
- **DRAM 依赖**：在有 DRAM 的 SSD 中才可获得最佳效果（99.7%），DRAM-less 配置（pSLC）效果大幅下降，限制了在低成本/嵌入式场景的适用性。
- **基线覆盖有限**：未与 Cambricon-LLM（纯 ISC + 外部 NPU）、其他非易失性 PIM（ReRAM）等主流替代路线进行对比，无法判断相对最优方案的差距。
- **SV 计算并行度受限**：由于 token 维大小远大于头维度，单次迭代可并行的 V 头数量少，注意力层的吞吐提升空间仍有局限。
