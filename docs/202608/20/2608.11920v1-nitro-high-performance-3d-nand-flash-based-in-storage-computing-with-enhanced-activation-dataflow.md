## 摘要
存储内计算（ISC）被认为是一种下一代内存架构，因为它能够缓解主机与内存之间的数据瓶颈。尽管近年来大语言模型（LLMs）所需的资源显著增加，但内存密度并未相应扩展。最近，已有若干工作研究了基于NAND闪存的存内处理（NAND-PIM）方案，以利用内存的高密度。然而，这些工作并未解决中间值的数据流/缓冲区问题，因此一种简单的方法是直接处理慢速闪存阵列中的中间值。为了克服这一限制，我们提出了一种高性能的基于NAND闪存的ISC架构，并增强了激活缓冲。我们的架构不使用非常慢的闪存阵列来存储中间值，而是在快速的DRAM子系统中缓冲这些值。这种方法有效处理了当激活被编程到较慢的TLC NAND闪存时的高延迟惩罚。我们还为NAND-PIM阵列引入了一种分布式数据流方法。该方法通过高效的平面内数据映射来最大化计算并行性。结果表明，我们提出的架构实现了显著的性能提升，与基线相比，推理延迟降低了高达85%。

## Abstract
In-storage computing (ISC) is considered a next-generation memory architecture for its ability to relieve the data bottleneck between the host and the memory. While the required resources of large language models (LLMs) have increased significantly in recent years, the memory density has not scaled accordingly. Recently, several works have studied NAND flash-based processing-in-memory (NAND-PIM) schemes to exploit the high density of the memory. However, they do not address the dataflow/buffer for the intermediate values, so a simple method is to deal with the values in the slow flash memory array. To overcome such a limitation, we propose a high-performance NAND flash-based ISC architecture with enhanced activation buffering. Instead of using the very slow flash memory array for the intermediate values, our architecture buffers the values in a fast DRAM subsystem. This approach effectively handles the high-latency penalties when activations are programmed into slower TLC NAND flash. We also introduce a distributed dataflow approach for the NAND-PIM array. This approach maximizes computational parallelism by employing efficient intra-plane data mapping. The results show that our proposed architecture achieves significant performance improvements, reducing the inference latency by up to 85% compared to the baseline.

- **整体含义**：本工作提出了一种高性能3D NAND闪存存储内计算架构NITRO，通过**快速DRAM缓冲中间激活值**并引入**分布式数据流方法**，同时发挥NAND闪存的高密度优势和DRAM的低延迟特性，为LLM推理加速提供了一条新路径。

## 2. 论文提出的方法论

### 2.1 核心思想

NITRO的核心思路是构建**异构PIM架构**——将NAND-PIM与DRAM-PIM集成在同一SSD子系统内，根据计算特征将不同类型的Transformer计算块映射到最合适的PIM子系统：

- **线性块（Linear Blocks）**：涉及大量输入激活与静态权重间的大规模矩阵乘法（MMM），权重在推理期间无需重新编程，故映射到高密度的TLC NAND-PIM阵列执行；
- **注意力块（Attention Blocks）**：涉及激活值与激活值之间的乘法（如 QKᵀ），若在NAND中执行需将中间矩阵编程回闪存，产生严重瓶颈，故卸载到快速的DRAM-PIM执行；
- **中间激活缓冲**：层间生成的中间激活值（如K、V矩阵）写入DRAM缓冲器，而非慢速的NAND闪存阵列。

### 2.2 关键技术细节

1. **激活DRAM缓冲（Activation DRAM Buffering）**：
   - 传统基准方案中，生成Q₀和K₀后需先将K₀ᵀ编程到NAND单元才能计算Q₀K₀ᵀ，编程期间NAND-PIM处于空闲状态，且后续A₁的处理也因资源竞争而停滞。
   - NITRO将K₀等中间激活快速写入DRAM缓冲器，随后以低延迟转置写入DRAM-PIM，Q₀K₀ᵀ的计算在DRAM侧低延迟完成，大幅减少了空闲时间和推理延迟。
   - 针对**无DRAM的SSD配置**，NITRO还支持将中间数据缓冲和注意力计算映射到以pSLC模式运行的NAND块（pSLC编程快于TLC但仍慢于DRAM），论文对pSLC和DRAM两种情况均进行了实验分析。

2. **分布式数据流（Distributed Dataflow）**：
   - **线性块**：将权重矩阵（W）在转置后沿垂直方向划分为W₀和W₁，分发到不同平面（Plane 0/1）；同时将激活矩阵A水平划分为A₀和A₁。A₀分别与Plane 0和Plane 1中的W₀、W₁相乘，A₁在Plane 2和Plane 3中并发执行相同操作，实现token级并行，部分输出矩阵通过拼接得到最终结果。在解码阶段（A为单向量时），采用广播方式同时向多个平面注入输入向量。
   - **注意力块**：
     - 在DRAM-PIM场景下，多个注意力头分布到不同的DRAM bank中，利用bank级并行独立计算各头的注意力操作（如QKᵀ）；
     - 在pSLC NAND场景下，多头键矩阵(KHᵀ)采用对角放置方案分布到不同BL组，多头查询矩阵(QH)经BLS解码器逐行输入。一次迭代只能处理部分头（如头0–i），因为若同一BL上累积两个不同头的电流，输出无法保证正确；
     - SV计算与QKᵀ不同：QKᵀ的向量大小方向点积较小，可并行处理大量头；SV的点积沿token大小方向进行，一次迭代能并发处理的值头数量受限（如仅2个头），需要更多迭代完成。

3. **NITRO架构实现**：
   - SSD内部集成NAND闪存子系统与DRAM子系统，由SSD控制器统一管理；
   - NAND闪存die包含4个独立平面，每个平面配备行列解码器、数据/缓存寄存器，以及PIM专用硬件：BLS解码器（按输入数据激活NAND串）、带积分器和电容的ADC（数字化模拟计算结果）、处理单元PE（数字累加PIM结果）；
   - 保留旁路路径以实现传统NAND闪存读/编程操作；
   - 权重以INT8量化存储：采用符号-幅值表示，7位幅值前补两个前导零形成9位表示，拆分为三部分存储在页方向上的多个物理单元中。正权重编程到偶数BL，负权重存储在相邻奇数BL；
   - MVM操作采用位串行输入处理（2's complement格式），通过成对BL的微分检测完成有符号计算，ADC数字化结果经PE移位、累加后生成最高16位的最终结果。

## 6. 论文的主要结论与发现

- **延迟降低**：NITRO（完整配置 + 注意力在DRAM-PIM）相比3D-FPIM基线，推理延迟降低最高达99.7%（归一化延迟约0.003）；相比S-FLASH基线降低约93.1%（归一化延迟约0.069）；
- **吞吐量提升**：NITRO相比3D-FPIM基线吞吐量提升约287倍，相比S-FLASH提升约14.5倍；
- **能量降低**：相比3D-FPIM基线，归一化能耗降低约98.9%；相比S-FLASH基线，平均能耗降低约72.6%；
- **关键发现**：使用DRAM作为激活缓冲区远比pSLC NAND有效。尽管pSLC单元操作更快，但页面式的多位数据布局（每字节至少7对BL）增加了ADC多路复用延迟，抵消了单元级速度优势，证明了DRAM是更合适的激活缓冲介质；
- **分布式数据流**的引入进一步优化了TLC NAND-PIM中线性块的执行效率，通过高效权重映射和多平面并行带来额外加速。

## 7. 优点

1. **问题定位精准**：识别出现有NAND-PIM方案在LLM推理中忽视中间激活值数据流这一关键缺口，并给出针对性解决方案；
2. **异构PIM的架构创新**：结合TLC NAND-PIM（存储密集型权重计算）与DRAM-PIM（数据密集型注意力计算）的混合架构，扬长避短，设计思路清晰合理；
3. **分布式数据流设计细致**：分别针对线性块和注意力块设计了垂直/水平分区策略、多平面并行、DRAM bank级头分布、pSLC对角放置等优化方案，兼顾了物理硬件约束；
4. **考虑实际硬件配置**：采用4平面TLC NAND、16KB页大小、16位SAR-ADC等贴近商用产品的参数配置，较此前工作更接近真实环境；
5. **全面的实验评估**：覆盖6种模型、2种基线、2种缓冲介质、3种配置，并增加了吞吐量指标和面积分析，评估维度较为完整；
6. **处理了DRAM-less SSD的替代方案**：对无DRAM配置提供了pSLC模式备选路径并单独评估，增强了方案适用范围。

## 8. 不足与局限

1. **缺乏精度评估**：论文基于假设（NAND单元变化与前期研究一致）省略了精度验证，对使用模拟电流和低分辨率ADC（如S-FLASH的稀疏场景）的精度影响未做实际量化；
2. **无真实硬件原型验证**：评估完全基于修改版NVSIM模拟器和综合工具，缺少实际芯片或FPGA原型验证，可能无法反映真实NAND阵列中的噪声、温度漂移、单元间干扰等非理想效应；
3. **ADC面积开销显著**：16位SAR-ADC在每个平面占用17.51 mm²，甚至超过部分DRAM-PIM bank的整个面积（7.08 mm²），大面积的ADC是实际部署中不可忽视的成本；
4. **pSLC配置下性能增益有限**：当注意力块映射到pSLC NAND时，延迟降低效果远不如DRAM方案（归一化延迟约0.29–0.448），且与TLC-only基线相比能量消耗几乎无改善，存在一定局限性；
5. **未考虑NAND闪存的擦除（erase）操作**：在权重重新编程或pSLC缓冲页面回收时，NAND需要块级擦除操作（通常需要毫秒级时间），论文的分析中未包含这一因素的影响；
6. **S-FLASH基线的对比不完整**：BL+AB配置在pSLC下被省略，且S-FLASH的位级稀疏优势在INT8稠密模型中的发挥程度未做深入分析；
7. **基线方案可能被低估**：3D-FPIM和S-FLASH原本是面向简单DNN设计的，将其直接扩展到大型Transformer模型可能未充分利用其优化潜力，这种比较对于基线方案可能不完全公平；
8. **未与GPU/NPU等传统加速器对比**：论文仅在NAND-PIM方案间对比，未与主流GPU或专用AI加速芯片进行性能/能耗比较，无法判断NITRO在真实系统中的相对竞争力。
