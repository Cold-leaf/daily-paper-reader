## 摘要
扩散变换器（DiTs）由于采样过程中反复评估由线性运算主导的大型去噪器，导致高内存流量和能量开销。模拟存内计算（CIM）可通过在存储权重的存储阵列中执行线性运算来缓解这些开销。然而，CIM非理想性会扰动有效权重，且误差沿状态相关的去噪轨迹累积；其与无分类器引导（CFG）的交互尚未得到充分探索。本文表征了模拟CIM非理想性对DiT采样的影响。尽管条件预测和无条件预测各自可能接近其干净对应项，但它们的差异（即CFG残差）会被不成比例地衰减和旋转。我们将该残差识别为可控失效通道，并提出一种免重训练、采样器侧的重新校准方法，该方法仅针对给定的CIM条件调整CFG尺度。轨迹级分析表明，适度的重新校准会增强失真残差中保留的目标导向分量，从而使得更早地承诺于与提示一致的语义区域成为可能。相反，过度的引导会放大完整噪声残差并降低质量，导致存在一个有限的、依赖噪声的最优点。在PixArt-Sigma、PixArt-alpha和DiT-XL/2上的大量实验表明，最优引导尺度随CIM噪声增加而增大。每种条件下使用30,000个样本，引导重新校准在模拟CIM映射下持续恢复生成质量，在CIM噪声水平为0.20时至少弥合了CIM引起的FID差距的87%。它将PixArt-Sigma上的FID从59.22降至20.49，PixArt-alpha上从72.37降至21.12，DiT-XL/2上从20.89降至6.62。

## Abstract
Diffusion Transformers (DiTs) incur high memory traffic and energy costs because sampling repeatedly evaluates large denoisers dominated by linear operations. Analog compute-in-memory (CIM) can alleviate these costs by executing linear operations within weight-storing memory arrays. However, CIM nonidealities perturb effective weights, with errors accumulating along the state-dependent denoising trajectory; their interaction with classifier-free guidance (CFG) remains underexplored. In this paper, we characterize the impact of analog CIM nonidealities on DiT sampling. Although conditional and unconditional predictions can each remain close to their clean counterparts, their difference (the CFG residual) is disproportionately attenuated and rotated. Identifying this residual as a controllable failure channel, we propose a retraining-free, sampler-side recalibration that adjusts only the CFG scale for a given CIM condition. Trajectory-level analysis shows that moderate recalibration strengthens the target-oriented component preserved in the distorted residual, enabling earlier commitment to a prompt-consistent semantic region. In contrast, excessive guidance amplifies the full noisy residual and degrades quality, resulting in a finite, noise-dependent optimum. Extensive experiments on PixArt-Sigma, PixArt-alpha, and DiT-XL/2 show that the optimal guidance scale increases with CIM noise. Using 30,000 samples per condition, guidance recalibration consistently restores generation quality across simulated CIM mappings, closing at least 87% of the CIM-induced FID gap at a CIM noise level of 0.20. It reduces FID from 59.22 to 20.49 on PixArt-Sigma, 72.37 to 21.12 on PixArt-alpha, and 20.89 to 6.62 on DiT-XL/2.

### 1. 论文的核心问题与整体含义（研究动机和背景）

扩散变换器（Diffusion Transformers, DiTs）在图像生成中表现出色，但采样过程需要反复评估大型去噪器，涉及大量的线性运算，导致高昂的内存流量和能量开销。模拟存内计算（Analog Compute-in-Memory, CIM）通过在存储权重的内存阵列内执行线性运算，能有效减少数据搬运，提升能效，因此被认为是部署DiT的有前景的硬件方案。

然而，模拟CIM存在固有的非理想性（如编程变异、电导漂移、读取噪声等），会扰动网络的有效权重。与一次性前馈推理任务不同，扩散采样是一个闭环迭代过程，误差会沿状态相关的去噪轨迹累积放大。现有研究主要关注CIM加速扩散模型的硬件效率或总体生成退化，但尚未深入探究CIM非理想性如何影响无分类器引导（Classifier-Free Guidance, CFG）这一扩散采样的核心条件控制机制。

本文的核心发现是：尽管CIM噪声下条件预测和无条件预测各自与干净数字推理结果相比偏差不大，但两者之差（即CFG残差）会被**不成比例地衰减和旋转**。这种对减法敏感的失真使得在干净条件下选定的CFG引导尺度在CIM部署后失配，导致生成质量显著下降。由此，论文识别出CFG残差是CIM部署下的一个关键失效通道，并据此提出解决方案。

**核心思想**：将CFG残差视为CIM非理想性下的失效通道，通过仅调整CFG引导尺度这一采样端控制变量来重新校准，无需重新训练或修改模型、调度器及采样预算。

**关键技术细节与公式**：

- **CIM部署建模**：将线性层（注意力Q/K/V投影、输出投影及前馈层）映射到CIM阵列，其他操作（归一化、激活、softmax、采样器更新）保持数字计算。权重扰动建模为：
  ```
  W̃ℓ = Wℓ ⊙ (1 + σCIM Ξℓ)，[Ξℓ]ij ~ N(0, 1)
  ```
  其中σCIM控制扰动强度，一次采样实现固定在整个去噪轨迹中。

- **CFG残差分解**：CFG组合为 εw,t = ut + w·gt，其中 gt = ct − ut。在CIM非理想性下，噪声残差可分解为与干净残差对齐的分量和正交分量：
  ```
  g̃t = αt·gt + ηt，αt = ⟨g̃t, gt⟩/‖gt‖²₂，⟨ηt, gt⟩ = 0
  ```
  代入CFG得：ε̃w,t = ut + δu,t + w(αt·gt + ηt)

- **引导尺度重校准**：给定独立校准集D_cal和候选尺度集W，选择最优尺度：
  ```
  w⋆(C) = arg min_w∈W L(w; D_cal, C)
  ```
  其中C为目标CIM运行条件（以σCIM索引），L为主实验中的FID。选择的尺度固定用于后续所有同条件下的采样。

- **轨迹级解释**：将重校准视为闭环采样过程的轨迹级控制问题。局部线性化分析表明，增加w能增强残差中保留的目标导向分量（αt·gt），帮助轨迹更早进入目标一致的语义盆地；但过度增大w会同样放大正交失真分量（ηt）并累积误差，因此存在有限的最优值。
