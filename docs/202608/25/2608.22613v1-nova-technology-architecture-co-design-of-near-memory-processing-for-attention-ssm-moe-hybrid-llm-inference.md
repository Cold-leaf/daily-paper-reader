## 摘要
混合大语言模型（LLMs）的快速发展，将分组查询注意力（GQA）、状态空间模型（SSM）和混合专家（MoE）层交错组合，给近内存处理（NMP）架构带来了两个根本性挑战。首先，技术壁垒：传统的6F^2 DRAM单元在10纳米级节点正接近其物理缩放极限，难以满足具有数百个专家的MoE模型的内存容量需求。其次，架构壁垒：现有的NMP设计针对狭窄的算术强度（Op/B）范围，无法高效支持混合LLM的异构计算特性，涵盖内存受限的SSM层、计算密集型的GQA层以及跨专家的大Op/B变化。我们提出了NOVA，一种技术与架构协同设计的NMP系统，同时克服了这两大壁垒。在技术方面，NOVA将4F^2垂直沟道晶体管（VCT）DRAM单元与单元上外设（POC）结构相结合，在等面积下相比传统基于6F^2的DRAM实现了约2倍的内存密度，从而能够持续扩展到10纳米以下节点。在架构方面，NOVA重新利用POC外设芯片（peri-die）来承载处理单元，形成两层NMP架构：第一层（peri-die NMP）用于低到中等Op/B操作，第二层（base-die NMP）用于中到高Op/B操作。跨层的并行执行支持混合LLM的多样化计算模式，最大化推理性能。在包括Nemotron3-Nano、Nemotron3-Super、Falcon-H1R和Qwen3在内的最先进混合及MoE LLM上评估，NOVA相比GPU基线平均实现了4.5倍的吞吐量提升、69.8%的端到端延迟降低和5倍的能效提升，且面积开销仅为3.9%，内存容量无损失。

## Abstract
The rapid evolution of hybrid large language models (LLMs), which interleave grouped-query-attention (GQA), state-space model (SSM), and Mixture-of-Experts (MoE) layers, introduces two fundamental challenges for near-memory processing (NMP) architectures. First, the Technology Wall: the conventional 6F^2 DRAM cell is approaching its physical scaling limits at 10nm-class nodes, making it difficult to meet the memory capacity demands of MoE models with hundreds of experts. Second, the Architecture Wall: existing NMP designs target narrow arithmetic intensity (Op/B) ranges and cannot efficiently support the heterogeneous compute characteristics of hybrid LLMs, spanning memory-bound SSM layers, compute-intensive GQA layers, and large Op/B variations across experts. We propose NOVA, a technology-architecture co-designed NMP system that overcomes both walls. On the technology side, NOVA combines a 4F^2 vertical channel transistor (VCT) DRAM cell with a peri-over-cell (POC) structure to achieve approximately 2x memory density at iso-area over conventional 6F^2-based DRAM, enabling continued scaling into sub-10nm nodes. On the architecture side, NOVA repurposes the POC peripheral-die (peri-die) to host processing units, forming a 2-tier NMP architecture: Tier-1 (peri-die NMP) for low-to-mid Op/B operations, and Tier-2 (base-die NMP) for mid-to-high Op/B operations. Parallel execution across tiers supports diverse compute patterns for hybrid LLMs, maximizing inference performance. Evaluated on state-of-the-art hybrid and MoE LLMs including Nemotron3-Nano, Nemotron3-Super, Falcon-H1R, and Qwen3, NOVA achieves on average 4.5x higher throughput, 69.8% lower end-to-end latency, and 5x better energy efficiency over a GPU baseline, with only 3.9% area overhead and no loss in memory capacity.

- 现代 LLM 推理中，**内存带宽和容量**已成为主要瓶颈：长上下文、大 batch、MoE 规模扩大，分别使 KV Cache、SSM 状态和专家权重快速增长。
- 混合 LLM（交错堆叠 GQA、SSM、MoE 层）进一步加剧了计算特征的异构性：
  - SSM 以低 Op/B、内存受限为主；
  - GQA 在 decode 阶段 Op/B 受 KV 复用比例影响；
  - MoE 中 hot/cold expert 的 token 分配极不均衡，导致 Op/B 波动很大。
- 现有 NMP 架构面临两大壁垒：
  - **Technology Wall**：传统 6F² DRAM 单元在 10nm 级以下难以继续缩放，无法满足 MoE 带来的容量需求；
  - **Architecture Wall**：in-die NMP、base-die NMP、HB NMP 等各自只覆盖窄 Op/B 区间，无法高效支持混合 LLM 的异构计算。

论文提出的 **NOVA** 是一种“存储技术—体系结构协同设计”的近内存处理系统，旨在同时解决上述两个壁垒，为 Attention-SSM-MoE 混合 LLM 推理提供高吞吐、低延迟、高能效的可扩展方案。

# 2. 方法论：核心思想与关键技术

## 2.1 技术层面：4F² VCT DRAM + Peri-Over-Cell（POC）

- 采用 **4F² 垂直沟道晶体管（VCT）DRAM 单元**，替代传统 6F² BCAT 单元，在等面积下获得约 1.5× 密度提升；
- 采用 **Peri-Over-Cell（POC）结构**，将 SWD、BLSA 等外围电路通过混合键合（HB）堆叠到 cell array 之上，使外围与存储阵列完全重叠，进一步获得约 1.39× 密度提升；
- 两者合并后，NOVA 在等面积下实现约 **2.09×（约 2×）存储密度**，可扩展到 sub-10nm 节点；
- 与 PUC 相比，POC 避免了 BEOL 布线资源占用，面积效率更高。

## 2.2 架构层面：2-Tier NMP

NOVA 由 cell-die、peri-die、base-die 三类裸片构成，并将 POC 的 peri-die 重新利用为近内存计算层：

- **Tier-1（Peri-die NMP）**：
  - 面向低到中等 Op/B 操作（SSM、cold expert、低复用 GQA）；
  - 包含 bank 级处理单元 BAPU 和 bank-group 级处理单元 BGPU；
  - BAPU 支持 SSM 状态更新和 GEMV；BGPU 支持 softmax、激活、累加等后处理。

- **Tier-2（Base-die NMP）**：
  - 面向中到高 Op/B 操作（高复用 GQA、hot expert）；
  - 在 base-die 上放置更强算力的 Base-PU，通过 TSV 访问 cell-die；
  - 具有更高算力但带宽相对受限，与 Tier-1 形成互补。

- **三种执行模式**：
  1. Tier-1-only：用于极低 Op/B 操作；
  2. Tier-2-only：用于高 Op/B 操作；
  3. Cross-Tier Parallel：Tier-1 与 Tier-2 并行执行，覆盖中等 Op/B 操作。

- **数据映射**：GQA/SSM 按 batch/head 在 cube 和 channel 间划分，MoE 按 expert 划分；映射完全确定性，KV cache、SSM state、expert weight 在整个 decode 阶段无需运行时重定位。

- **操作级执行流程**：
  - GQA：分别在 Tier-1 和 Tier-2 上进行 tiled FlashAttention-2 风格计算，Tier-1 使用 2-tile interleaving 隐藏 softmax 延迟；
  - SSM：完全在 Tier-1 执行，通过 EWM/EWA 完成状态更新，并让状态写回与 GEMV 输出计算重叠；
  - MoE：cold experts 在 Tier-1、hot experts 在 Tier-2 并行执行，并采用自适应 hot/cold 分配策略，利用路由统计在运行时动态调整比例。

# 6. 主要结论与发现

- NOVA 相比 GPU 基线，平均获得：
  - **4.5× 更高吞吐量**；
  - **69.8% 更低端到端延迟**；
  - **5× 更好能效**；
  - 仅 **3.9% 面积开销**，且不损失内存容量。

- 在混合模型上，NOVA 平均加速约 4.2×（最高 5.8×）于 GPU；在 Qwen3 上平均加速约 4.8×（最高 6.6×）。

- 消融实验表明，2-tier 并行与 POC + 4F² 技术均贡献显著；NOVA 比“in-die + base-die”组合高 1.7×（Nemotron3-Nano）和 3.0×（Qwen3）。
- 长上下文场景下，NOVA 是唯一能在 256K 输入长度运行而不 OOM 的设计，说明 2× 密度优势可将不可行配置变为可行。

# 7. 优点

- **技术-架构协同设计**：不是简单堆叠 PUs，而是将 4F² VCT、POC 等存储工艺创新与双层 NMP 架构深度结合；
- **同时解决两个壁垒**：既提升密度（解决容量），又覆盖宽 Op/B 区间（解决异构计算）；
- **零容量损失**：PUs 放在 peri-die 和 base-die，不占用 cell array 面积，优于 in-die NMP 的 20%+ 面积损失；
- **跨层并行**：Tier-1 和 Tier-2 使用独立带宽路径（HB 与 TSV），可叠加 roofline，提升更广 Op/B 区间的吞吐；
- **低迁移成本、高灵活性**：数据映射与 tier 无关，在 decode 过程中可动态调整 hot/cold 分配，无需移动权重；
- **面积开销极低**：BAPU 被隐藏在 POC 结构下方，Base-PU 利用 base-die 空闲面积，整体仅 3.9% 额外面积；
- **长上下文可行性**：2× 密度显著扩展了可服务的序列长度范围。

# 8. 不足与局限

- **依赖尚未成熟的存储工艺**：4F² VCT 和 POC 是前沿/近未来 DRAM 技术，论文基于工艺文献假设，尚缺少大规模量产验证；
- **模拟评估为主**：结果来自 Ramulator2 周期级模拟和 RTL 综合，未在真实 NMP 芯片上验证；
- **偏重 decode 阶段**：prefill、投影层、部分计算仍留在 GPU，NOVA 不是全阶段端到端加速方案；
- **能效存在权衡**：在 Qwen3 上，NOVA 的能效低于 Duplex；cross-tier 并行模式为追求高吞吐会增加激活功耗；
- **部分基线配置受限**：AttAcc、PIMBA 不支持的操作需回退 GPU，可能影响对比公平性；
- **评估规模有限**：仅使用 4 个模型、BF16 精度、固定 batch/seq 网格，未覆盖连续 batching 的完整长时动态、量化精度、多租户服务等实际场景；
- **论文未披露绝对功耗和能耗数值**，只报告归一化相对值，难以判断绝对能效。
