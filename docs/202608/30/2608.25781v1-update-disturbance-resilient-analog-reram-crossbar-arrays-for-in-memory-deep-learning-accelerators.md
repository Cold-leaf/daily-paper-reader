## 摘要
具有交叉阵列架构的阻变存储器（ReRAM）技术在模拟AI加速器硬件方面具有巨大潜力，能够实现内存推理和训练。最近的发展已经通过将计算密集的训练负载卸载到片外数字处理器，成功展示了推理加速。然而，训练算法的内存加速对于更可持续和节能的AI至关重要，但仍处于研究早期阶段。本研究利用模拟ReRAM阵列解决内存训练加速问题，重点关注全并行权重更新期间的一个关键挑战：交叉点设备中权重值的扰动。提出了一种基于350纳米硅工艺的ReRAM器件解决方案，利用在HfOx层内纳米级导电细丝上形成的阻变导电金属氧化物（CMO）。这些器件不仅表现出60纳秒快速、非易失性模拟开关特性，而且展现出卓越的抗更新扰动能力，可承受超过10万次脉冲。使用COMSOL Multiphysics模拟分析了ReRAM的扰动容限，建模了细丝诱导的热电能量集中，导致器件对输入电压幅度的高度非线性响应。还在后端集成ReRAM阵列芯片上演示了无扰动并行权重映射。最后，全面的硬件感知神经网络模拟验证了我们的ReRAM在能够完全并行权重更新的内存深度学习加速器中的潜力。

## Abstract
Resistive memory (ReRAM) technologies with crossbar array architectures hold significant potential for analog AI accelerator hardware, enabling both in-memory inference and training. Recent developments have successfully demonstrated inference acceleration by offloading compute-heavy training workloads to off-chip digital processors. However, in-memory acceleration of training algorithms is crucial for more sustainable and power-efficient AI, but still in an early stage of research. This study addresses in-memory training acceleration using analog ReRAM arrays, focusing on a key challenge during fully parallel weight updates: disturbances of the weight values in cross-point devices. A ReRAM device solution is presented on 350 nm silicon technology, utilizing a resistive switching conductive metal oxide (CMO) formed on a nanoscale conductive filament within a HfOx layer. The devices not only exhibit 60 ns fast, non-volatile analog switching, but also demonstrates outstanding resilience to update disturbances, enduring over 100k pulses. The disturbance tolerance of the ReRAM is analyzed using COMSOL Multiphysics simulations, modeling the filament-induced thermoelectric energy concentration that results in a highly nonlinear device responses to input voltage amplitudes. Disturbance-free parallel weight mapping is also demonstrated on the back-end-of-line integrated ReRAM array chip. Finally, comprehensive hardware-aware neural network simulations validate the potential of our ReRAM for in-memory deep learning accelerators capable of fully parallel weight updates.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：ReRAM 交叉阵列凭借高可扩展性、低功耗和模拟阻变能力，被认为是构建模拟 AI 加速器的理想器件。目前推理加速已较成熟，但**训练过程的存内加速**仍处于早期阶段——现有系统通常将计算密集的训练任务卸载到外部数字处理器，带来巨大的能耗和通信开销。
- **核心问题**：在实现存内训练时，全并行权重更新（outer-product update）要求同一阵列中所有交叉点器件同时被脉冲驱动，但**非目标器件会承受半幅电压（half Vs）非重合脉冲**，导致权重值发生不希望的漂移，即“更新扰动”（update disturbance）。高精度数字存储中对扰动的容忍标准不适用于模拟突触器件——即使微小扰动也可能在持续学习中累积并严重破坏收敛。
- **解决思路**：理想器件应对输入电压幅度具有**强非线性开关响应**——重合的全幅脉冲才触发写入，非重合的半幅脉冲不改变状态。作者提出一种基于 HfOx 中预形成 CMO 导电细丝（CF）的模拟 ReRAM，利用细丝诱导的热电能量集中实现该非线性，从而从器件层面根本解决扰动问题，避免在交叉点增加额外晶体管带来的密度和扩展性损失。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想**：
- 利用预形成的刚性纳米级导电细丝（CF）将阻变区域局域化——器件切换行为由细丝尖端的半球形 CMO 区域主导，而非整个器件面积。
- 外加电压时，细丝尖端电场高度集中 → 局部焦耳热显著增强 → 离子迁移率随温度指数上升（Arrhenius 关系）。因此，阻变对电压幅度呈**高度非线性**响应，半幅脉冲不足以触发开关。
- 采用 Gokmen 等人提出的**随机脉冲编码**方案实现 O(1) 时间复杂度的全并行外积更新：将前向激活 x 和反向误差 d 编码为随机脉冲序列，输入到阵列行列，重合脉冲（全幅 Vs）既执行梯度计算又驱动权重更新。

**关键技术细节**：
- 器件结构：TiN/CMO（20 nm）/HfOx（4 nm）/TiN 堆叠，CMO 为阻变导电金属氧化物层。
- 形成过程：施加控制电压和电流形成刚性 CF，平均形成电压 2.8 V。
- 开关机制：正脉冲将缺陷（氧空位）驱动回 CF 上方半球形区域 → 低阻态；负脉冲使缺陷迁移离开 → 高阻态。
- 器件性能：60 ns 快速开关（+1.6 V set / -2.3 V reset）；微秒级脉冲用于阵列测试（+1.4 V/-1.9 V，2.5 μs）。

**关键公式**：
- 随机脉冲编码的外积：P(x)P(d)ᵀ = [p(xᵢ)p(dⱼ)]，重合脉冲数正比于期望更新量 ηxᵢdⱼ。
- 非线性因子 k = Δg(0.5Vs) / Δg(Vs)，理想值为 0。
- 软边界模型（soft-bounds model）：Δw⁺ = α⁺(w̄max − w)/w̄max，Δw⁻ = −α⁻(w̄min − w)/w̄min，含 cycle-to-cycle 噪声 σcₜₒc 和 device-to-device 噪声 σdₜₒd。
- 扰动扩展：全幅脉冲用 Δw±，半幅脉冲用 Δw±·σ±k。
- 权重更新迭代：w ← w + Δw。

**COMSOL 仿真**：3D 有限元求解稳态连续性方程和焦耳热方程，提取电场、温度分布，估算 CF 半径约 11 nm，定量揭示细丝尖端电场集中与温度热点，以及 TMax 随电压的非线性增长。
