## 摘要
随着神经推理和传感器边缘分析等现代数据密集型应用的扩展，它们日益遭遇冯·诺依曼存储墙，承受过高的数据移动开销和严格的能量约束。利用新兴非易失性技术（如磁隧道结，MTJ）的存内计算（IMC）有望缓解这些瓶颈。然而，传统的基于二进制基数（radix）的IMC架构面临对工艺引起的变异的过度脆弱性、受限的工作裕度和热噪声。为弥合能效与计算可靠性之间的差距，本工作提出FALCON，一种将容错、基于MTJ的存内算术架构与随机计算（SC）相结合的设计。通过将数值编码为均匀比特流，SC天然吸收局部软错误，并能够直接在存储阵列内使用高度紧凑的逻辑原语执行算术运算的基本套件。FALCON将确定性比特映射机制与可重构存内逻辑（LIM）结构集成，无需将数据传输至外部处理器或面积和功耗密集的随机数生成器。使用14纳米FinFET技术的实验结果验证了即使在激进电压缩放、严重工艺变异和高达30%噪声注入水平下，FALCON也能正确运行功能，使其成为可靠性关键型边缘AI应用的稳健框架。我们以形态学闭合作为现实的抗噪图像处理案例，研究了FALCON的正确功能。

## Abstract
As modern data-centric applications such as neural inference and sensor-edge analytics expand, they increasingly encounter the von Neumann memory wall, suffering from excessive data movement overhead and stringent energy constraints. In-Memory Computing (IMC) utilizing emerging non-volatile technologies, such as Magnetic Tunnel Junctions (MTJs), promises to mitigate these bottlenecks. However, conventional binary radix-based IMC architectures suffer from excessive vulnerability to process-induced variations, restricted operating margins, and thermal noise. To bridge the gap between energy efficiency and computational reliability, this work proposes FALCON, a fault-tolerant, MTJ-based in-memory arithmetic architecture integrated with Stochastic Computing (SC). By encoding numerical values into uniform bit-streams, SC naturally absorbs localized soft errors and enables the execution of an essential suite of arithmetic operations using highly compact logic primitives directly within the memory arrays. FALCON integrates a deterministic bit mapping mechanism with reconfigurable logic-in-memory (LIM) structures, eliminating the need to transfer data to external processors or area- and power-hungry random number generators. Experimental results using 14 nm FinFET technology validate the correct functionality of FALCON even under aggressive voltage scaling, severe process variation, and noise injection levels up to 30%, making it a robust framework for reliability-critical edge AI applications. We investigate the proper functionality of FALCON on morphological closing as a realistic noise-tolerant image processing case study.

- **论文的意义**：为“能效 vs. 可靠性”难以兼得的存内计算场景提供了系统性的容错算力方案，面向可靠性关键型边缘 AI 应用。

## 2. 论文提出的方法论：核心思想、技术细节与流程

提出的系统称为 **FALCON**，核心是将**常规定点二进制算术**迁移为**存内随机算术**，架构包含三个层次：

- **Bit-Stream Generation Unit（比特流生成单元）**
  - 采用**确定性低偏差（LD）比特映射**方案，将 n-bit 二进制输入转为长度为 N=2ⁿ 的比特流。
  - 每位二进制数字 Xi 复制 2ⁱ 次，并按一组确定性 LD 模板放在特定位置（如图 2a 的 Pattern 1~3），生成无采样噪声的准确概率表示。
  - 通过选择相同模板（生成“相关比特流”）或不相同模板（生成“独立比特流”）来控制跨流相关性——该机制直接决定后续运算的类型，并完全省略传统 SC 中的 RNG 电路。
- **In-Memory SC Arithmetic Engine（存内随机算术引擎）**
  - 复用基于 MTJ 的**可重构逻辑存内计算（LIM）结构**作为底层原语单元（图 2b）。
  - FALCON 用这些 LIM 单元分别实现 `AND / OR / XOR / MUX` 等逻辑，并构成一套可在内存内直接完成的算术运算集：
    - 乘法（不相关比特流，用 AND）
    - 最小值（相关比特流，AND）、最大值（相关比特流，OR）
    - 绝对值减法（相关比特流，XOR）
    - 缩放加减法、除法（用 MUX 并配合控制比特流）
  - 计算全程不发生数据搬移，直接在存储阵列中以逻辑原语执行。
- **Bit-stream to Binary decoder（比特流转二进制单元）**
  - 末尾如需要，可通过纯基于 LIM 的电路把输出比特流转换回二进制，实现 SC 到二进制域的重新接轨。

## 6. 论文的主要结论与发现

- **FALCON 在严苛环境下功能保持正确**：在流程变化 10%、噪声高至 30%、电压降至 0.7 V 的情况下仍然可完成所有 6 种算术运算，说明其容错能力源自 SC 表示而非单纯依赖电压裕度。
- **噪声鲁棒性规律明确**：比特流长度越长，MAE 越低且耐噪性更强，例如 N=16 时乘法的 30% 噪声 MAE 为 19.6%，N=1024 时降为 17.8%（相对于低噪环境下提升明显）；
- **确定性 LD 映射**避免随机数生成的成本与误差，同时能够精确控制流间相关性，是保证算术精度的重要设计基础。
- **能效显著**：0.8 V 时降低 27%，0.7 V 时功耗降低 51%；且相比 von Neumann 架构处理同尺寸图像能获得 ~10×能量节约。
- **对形态学图像处理**：在 30% 噪声下 FALCON 的 IoU 达到 0.89，而常规二值 IMC 只有 0.64——呈现出“噪声下依旧稳健”的边缘智能处理模式。

## 7. 优点（方法与实验设计上的亮点）

- **架构创新**：在不依赖昂贵随机数源的前提下，把 SC 生成、算术运算与比特流转二进制三条流水线全部整合进 MTJ 存储阵列，实现了真正“端到端存内逻辑”，是相当完整、可直接存内复用的算术框架。
- **关联性机制精确可控**：LD 模板 + LIM 原语组合表达了设计者如何仅凭借比特流源相关性控制 AND 运算是“乘法”还是“最小值”，十分优雅。
- **对硬件的适应性强**：支持从 16-bit 到 1024-bit 任意比特流长度调节精度与噪声容忍，能适配不同场景需求；
- **可靠性实验相对扎实**：在噪声、工艺偏差、电压降三种故障源上同时做评估，并且展示了真实用例（形态学闭合）下与传统二进制方法的对比，使结论更有说服力。
- **低功耗逻辑原语**：AND/OR 等简单逻辑直接在内存中完成，MAC 类复杂运算通过简单基本门实现，对比传统多周期行激活方案具本质性复杂度优势。

## 8. 不足与局限

- **应用级验证较窄**：只测试了形态学图像闭合一个场景，尚未涉及神经网络推理、传感器标量融合等更普遍的边缘 AI 任务；论文标题所指的 AI 应用范畴未能充分以基准数据集（如 MNIST/CIFAR）量化和验证。
- **缺少与其他 SC-IMC 在同一仿真管线下的性能对比**：与 SCRIMP/SC-CRAM/DAC’25 等仅做表格对比，没有提供归一化 MAE 或端到端精度数据，公平性不易判定。
- **模型层面局限**：SC 编码隐含的比特流分布约束了运算精度上限——在乘法/除法等运算上 MAE 相对较高；复杂任务中当 N 较小时，精度损失可能不可接受。
- **能耗可能被低估**：如果将 MTJ 写操作寿命、字节-层间切换、同一阵列控制复杂性的额外开销计入，真实微瓦级功耗也会随数据规模扩展受影响。
- **未提供更大的阵列扩展设计与多 bank 协作能力分析**，缺少处理更大规模数据（大图像、嵌入向量等）时的阵列结构和长流处理说明。
- **未提及系统级纠错叠层**：若器件噪声超过 30%（强辐射等军工/航空场景）是否仍能可靠工作并未讨论，适应性边界不够分明。
