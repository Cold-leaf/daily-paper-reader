## 摘要
随着神经推理和传感器边缘分析等现代数据驱动应用不断扩展，它们日益遭遇冯·诺依曼存储墙，承受过高的数据搬运开销和严苛的能耗约束。利用新兴非易失性技术（如磁隧道结（MTJ））的存内计算（IMC）有望缓解这些瓶颈。然而，传统的基于二进制基数（radix）的IMC架构对工艺引起的波动、受限的工作裕度和热噪声表现出过度的脆弱性。为弥合能效与计算可靠性之间的差距，本工作提出FALCON——一种与随机计算（SC）集成的、基于MTJ的容错存内算术架构。通过将数值编码为均匀的比特流，SC天然地吸收局部软错误，并允许直接在存储阵列内使用高度紧凑的逻辑原语来执行一套基本的算术运算。FALCON将确定性比特映射机制与可重构的存内逻辑（LIM）结构相结合，从而无需将数据传输到外部处理器，也无需面积和功耗开销高昂的随机数发生器。基于14nm FinFET工艺的实验结果验证了即使在激进电压缩放、严重工艺波动以及高达30%的噪声注入水平下，FALCON仍能正确运行，使其成为可靠性关键型边缘AI应用的鲁棒框架。我们以形态学闭合作为现实场景中的容噪图像处理案例，研究了FALCON的正确功能。

## Abstract
As modern data-centric applications such as neural inference and sensor-edge analytics expand, they increasingly encounter the von Neumann memory wall, suffering from excessive data movement overhead and stringent energy constraints. In-Memory Computing (IMC) utilizing emerging non-volatile technologies, such as Magnetic Tunnel Junctions (MTJs), promises to mitigate these bottlenecks. However, conventional binary radix-based IMC architectures suffer from excessive vulnerability to process-induced variations, restricted operating margins, and thermal noise. To bridge the gap between energy efficiency and computational reliability, this work proposes FALCON, a fault-tolerant, MTJ-based in-memory arithmetic architecture integrated with Stochastic Computing (SC). By encoding numerical values into uniform bit-streams, SC naturally absorbs localized soft errors and enables the execution of an essential suite of arithmetic operations using highly compact logic primitives directly within the memory arrays. FALCON integrates a deterministic bit mapping mechanism with reconfigurable logic-in-memory (LIM) structures, eliminating the need to transfer data to external processors or area- and power-hungry random number generators. Experimental results using 14 nm FinFET technology validate the correct functionality of FALCON even under aggressive voltage scaling, severe process variation, and noise injection levels up to 30%, making it a robust framework for reliability-critical edge AI applications. We investigate the proper functionality of FALCON on morphological closing as a realistic noise-tolerant image processing case study.

## 2. 论文提出的方法论

### 核心思想
- 采用**随机计算（SC）**替换传统二进制编码：数值以均匀比特流中“1”的比例（概率）来表示，硬件故障或外部噪声导致的单比特翻转只会轻微信扰动最终结果——因为每个比特权重相同，不存在“高权重位”——从而天然吸收软错误。
- 将 SC 全套算术逻辑（乘法、除法、缩放加法、绝对减法、最小值、最大值）嵌入 MTJ 存储阵列内部，构建一个**存内 ALU**，避免数据搬运至外部处理器。
- 为克服传统 SC 依赖随机数生成器（RNG）开销大的问题，设计**确定性低差异（LD）比特映射**机制，利用 MTJ 常规读写操作在原位生成精确、可控制相关性的比特流。

### 关键技术细节
- **确定性比特映射（LDSG 编码器）**：对 n 位二进制输入 X = (Xₙ₋₁, …, X₀)，每个二进制位 Xᵢ 被复制 2ⁱ 次并放置在比特流中由预设低差异模式指定的位置上，生成 2ⁿ 长度的比特流。该方案彻底去除了面积和功耗开销巨大的随机数生成电路。
  - **相关性控制是关键**：两个输入使用相同的 LD 模式生成**相关**比特流，用于最小（AND）、最大（OR）和绝对减法（XOR）；使用不同的 LD 模式则生成**近似独立**的比特流，用于乘法（AND）。
- **可重构存内逻辑（LIM）单元**：每个单元含两个 MTJ（MTJ1/MTJ2）和一个参考 MTJ（MTJ3），外加 FinFET 外围晶体管和双输出敏感放大器。计算分两阶段：
  - **准备阶段（preparation）**：比特流驱动的双向写电流将两个 MTJ 编程为并行/反并行组合（HH、HL、LH、LL）；
  - **评估阶段（evaluation）**：加读电流，通过电阻分压确定输出，由敏感放大器同时产生互补逻辑输出。
  - 同一 LIM 单元可通过重构实现 AND/NAND、OR/NOR 逻辑，配合比特流相关性选择，即可在存储阵列内实现完整 SC 算术操作集。
- **存内比特流到二进制转换器**：计算完成后，结果比特流可由基于 LIM 的转换器（分 log₂N 步）转回二进制形式，用于后续处理。
- **具体操作映射**：
  - 乘法：对独立比特流执行逐位 AND；
  - 最小/最大：对相关比特流执行 AND/OR；
  - 绝对减法：对相关比特流执行 XOR；
  - 缩放加法/减法和除法：以控制比特流驱动 2:1 多路选择器（MUX）实现。

## 6. 论文的主要结论与发现

- **核心结论**：FALCON——结合确定性比特映射 MTJ 存内生成与可重构 LIM 计算的随机算术架构——能够在不依赖随机数发生器和外部数据搬运的前提下，在存储阵列内部执行完整的算术操作集，同时提供高水平的容错能力。
- **容错性**：在高达 30% 噪声注入、±3σ/10% 的工艺偏差、电压降至 0.7V 等多重不利条件下，所有算术操作仍保持功能正确。比特流越长，精度和抗噪能力越好（如 N=1024 乘法在 5% 噪声下 MAE 为 3.14%，N=64 时为 7.14%）。
- **能效**：0.8V 和 0.7V 下分别节省约 27% 和 51% 的总功耗；256×256 形态学闭合仅消耗 7.63 μJ；相比冯·诺依曼基线可降低约 10 倍能耗（主要归功于消除了数据搬运）。
- **鲁棒性比较**：在 30% 器件噪声 + 15% 椒盐噪声条件下，FALCON 形态学闭合同等条件下的 IoU 为 0.89，而传统二进制 IMC 仅 0.64，展示出明显的可靠性优势。
- 随机计算的确定性 LD 编码机制提供显式相关性控制，克服了噪声驱动 SC 设计（通过器件自身随机开关产生比特流）中无法有效管理比特流交叉相关性的结构性缺陷。

## 7. 优点

### 方法论优点
- **真正实现存内 ALU**：区别于仅支持单一或少量操作的 IMC 方案，FALCON 在存储阵列内实现了完整的 SC 算术操作集（加/减/乘/除/最大/最小），涵盖处理器 ALU 的基本功能。
- **以确定性机制替代随机性生成**：采用 LD 确定性比特映射，以 MTJ 常规读写方式原位生成比特流，从根本上消除 SC 系统中面积/功耗开销最大的 RNG 组件，并同时提供了显式的相关性控制能力——这是该方案区别于 SCRIMP、SC-CRAM 和 Stoch-IMC 的关键创新。
- **从模型层面解决可靠性问题而非事后纠错**：利用 SC 概率编码使得软错误的影响被均匀分摊，不需要 ECC 等冗余纠错机制，从计算范式层面增强抗扰能力。
- **能够在极端条件下运行**：0.7V 电压下仍功能正确，而许多传统二进制 IMC 在如此低电压下逻辑翻转裕度急剧恶化，凸显新方案的鲁棒性优势。

### 验证全面性优点
- 从行为级 → 电路级 → 系统级三个层面逐层验证，证据链较完整；瞬态波形（图 3）直观说明了 LIM 两阶段操作的正确时序行为。
- 对 SC 场景下的核心设计参数——比特流长度、噪声等级、LD 模式的相关性控制——均进行了变化分析，有助于应用场景下的参数选择。

## 8. 不足与局限

### 实验覆盖的局限
- **应用验证单一**：仅以形态学图像闭合作为案例，虽具代表性（使用了最大/最小操作），但未评估 FALCON 在更复杂的真实边缘 AI 工作负载（神经网络推理、信号分类、KNN 等）中的端到端表现。
- **缺乏周期精确的完整系统基准**：未提供 FALCON 与 SOTA 方案在相同工艺/输入条件下的精确延迟-功耗-面积（PPA）对比数据，表 III 多为定性/半定量描述（如列出自报告的能量数字），可能导致对比不够客观。
- **器件噪声来源覆盖有限**：文中注入的噪声为均匀随机比特翻转；真实 MTJ 阵列中的噪声通常在空间/时间上具有相关性，且 SET 可能造成多位连续翻转，该模型未覆盖此类模式。
- **未讨论面积开销**：LIM 单元、参考 MTJ、敏感放大器在存储密度上的代价未予量化，而这是 IMC 商用化的关键指标。
- **与二值 IMC 的性能对比不完整**：虽然强调 SC 的串行比特处理特性，但表 II 给出的时延数据体现的是单次逻辑操作的延迟，未折算完整操作（如 N=1024 时乘法全流程需 1024 周期）与二进制 IMC 全流程延迟的端到端对比。

### 应用限制
- SC 固有的**串行比特流处理**导致延迟随 N 线性增长；虽然任意精度可以通过增加 N 实现，但高精度场景下吞吐量可能无法与比特并行二进制 IMC 竞争。论文承认“延迟敏感的应用可选择更短的比特流”，但未给出具体延迟-精度权衡曲线（如误差/延迟 Pareto 曲线）。
- SC 无法高效表示大数值范围（分辨率随 N 呈指数增长），因此 FALCON 更适合**低动态范围、容错图像/信号任务**，但对于需要高精度大数运算（如科学计算、金融）的通用计算场景并不适用——论文未明确界定这一边界。
- 实际部署需要将图像阵列**逐个像素**编码为比特流并存储在 MTJ 中，对 8-bit 图像需要 256× 的存储开销（尽管 LD 模式可以优化存储方式，论文对此未给出量化评估）。

## 综合评价

FALCON 提出了一种在系统级设计层面具有新意的架构：将随机计算的容错属性嵌入 MTJ 存内计算框架中，并以确定性 LD 编码替代 RNG 解决了传统 SC 的成本瓶颈。实验由电路级仿真贯穿至应用级验证，证明了该架构在极端噪声、电压和工艺波动条件下仍具备生存能力。然而，从实际部署角度看，仍面临 SC 吞吐量上限、面积开销不透明以及应用场景相对受限等通用问题的挑战。总体而言，论文在能效—可靠性双重目标下的架构创新性较强，但仍有待更广泛的任务覆盖与更统一的基准数据支撑。
