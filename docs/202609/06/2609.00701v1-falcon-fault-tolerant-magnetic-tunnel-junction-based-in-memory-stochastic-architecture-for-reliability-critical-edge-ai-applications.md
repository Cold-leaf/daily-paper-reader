## 摘要
随着神经推理和传感器边缘分析等现代数据密集型应用的扩展，它们日益遭遇冯·诺依曼存储墙，饱受过度的数据移动开销和严格的能量约束之苦。利用新兴非易失性技术（如磁隧道结）的内存计算（IMC）有望缓解这些瓶颈。然而，传统的基于二进制基数的IMC架构容易受到工艺引起的变异、受限的工作裕度和热噪声的过度影响。为了弥合能效与计算可靠性之间的鸿沟，本工作提出FALCON，一种结合了随机计算（SC）的容错、基于MTJ的内存算术架构。通过将数值编码为均匀比特流，SC自然吸收局部软错误，并能够直接在内存储阵列中使用高度紧凑的逻辑原语执行一套基本的算术操作。FALCON集成了确定性比特映射机制与可重构的逻辑内存（LIM）结构，无需将数据传输到外部处理器或面积和功耗密集的随机数生成器。使用14 nm FinFET技术的实验结果验证了FALCON即使在激进电压缩放、严重工艺变异和高达30%的噪声注入水平下也能保持正确功能，使其成为可靠性关键型边缘AI应用的鲁棒框架。我们将FALCON在形态学闭合上的正确功能作为一个现实的容噪图像处理案例进行研究。

## Abstract
As modern data-centric applications such as neural inference and sensor-edge analytics expand, they increasingly encounter the von Neumann memory wall, suffering from excessive data movement overhead and stringent energy constraints. In-Memory Computing (IMC) utilizing emerging non-volatile technologies, such as Magnetic Tunnel Junctions (MTJs), promises to mitigate these bottlenecks. However, conventional binary radix-based IMC architectures suffer from excessive vulnerability to process-induced variations, restricted operating margins, and thermal noise. To bridge the gap between energy efficiency and computational reliability, this work proposes FALCON, a fault-tolerant, MTJ-based in-memory arithmetic architecture integrated with Stochastic Computing (SC). By encoding numerical values into uniform bit-streams, SC naturally absorbs localized soft errors and enables the execution of an essential suite of arithmetic operations using highly compact logic primitives directly within the memory arrays. FALCON integrates a deterministic bit mapping mechanism with reconfigurable logic-in-memory (LIM) structures, eliminating the need to transfer data to external processors or area- and power-hungry random number generators. Experimental results using 14 nm FinFET technology validate the correct functionality of FALCON even under aggressive voltage scaling, severe process variation, and noise injection levels up to 30%, making it a robust framework for reliability-critical edge AI applications. We investigate the proper functionality of FALCON on morphological closing as a realistic noise-tolerant image processing case study.

## 1. 论文的核心问题与整体含义

- 现代边缘 AI 应用（如神经推理、传感器边缘分析）日益面临**冯·诺依曼存储墙**：数据在存储与计算单元间的频繁搬运带来巨大开销和能耗。
- 采用新兴非易失器件（如磁隧道结 MTJ）的**存内计算（IMC）** 被认为是缓解该瓶颈的有效途径。
- 但传统二进制基数（binary radix）的 IMC 架构存在固有缺陷：
  - 对**工艺偏差、热噪声、电压波动**非常敏感；
  - 二进制表示具有“位权重大”的特性，单比特翻转可能造成严重错误；
  - 工作裕度受限，在深亚微米下面临可靠性退化。
- 因此，核心问题是如何在保证能效的同时，获得**计算层面的鲁棒性**。

## 2. 论文提出的方法论

### 核心思想
- 将**随机计算（Stochastic Computing, SC）**与**MTJ 基存内计算**结合：数值被编码为均匀比特流，用简单的逻辑门（AND、OR、XOR、MUX 等）在存储阵列内直接完成算术操作。
- SC 天然具有容错性：比特流中单个比特翻转只改变一个最小权重位，对整体数值影响很小。

### 关键技术细节

- **确定性比特映射（Deterministic Bit Mapping）**
  - 使用**低差异（Low-Discrepancy, LD）模式**将二进制数的每一位按权重复制到比特流中的特定位置，得到精确的概率表示，避免采样误差。
  - 无需传统 SC 所需的**随机数生成器（RNG）**，降低了面积与功耗开销。
  - 可选择相同或不同的 LD 模式来控制比特流之间的相关性：
    - 相同模式 → 相关比特流，用于 MIN（AND）、MAX（OR）、绝对减法（XOR）；
    - 不同模式 → 近似独立比特流，用于乘法（AND）。

- **可重构逻辑内存（LIM）结构**
  - 每个 LIM 单元由两个数据 MTJ（MTJ1/MTJ2）和一个参考 MTJ（MTJ3）及 FinFET 构成。
  - 两阶段操作：
    1. **准备阶段**：由输入比特流驱动写电流，将 MTJ 编程为平行/反平行状态；
    2. **评估阶段**：通过电阻分压和双输出读出放大器产生 AND/NAND 或 OR/NOR 等互补逻辑输出。
  - 同一阵列可重构实现不同 SC 逻辑原语。

- **完备的内存 SC 算术引擎**
  - 支持：乘法（AND）、缩放加法/减法/除法（MUX）、绝对减法（XOR）、最小值（AND）、最大值（OR）。
  - 算术操作全部在存储阵列内执行，无需向外部处理器传输数据。
  - 后端通过基于 LIM 的**比特流到二进制转换器**将结果还原为二进制。

- **工艺/电压鲁棒性来源于随机表示**
  - 电压波动或工艺偏差虽会干扰个别比特，但不会明显改变比特流中‘1’的比例，因此编码数值几乎不受影响。

## 6. 主要结论与发现

- FALCON 在 **14nm FinFET** 工艺下，即便在**激进电压缩放（0.7V）、严重工艺变化、以及高达 30% 的噪声注入**下，仍能保持算术功能正确。

- 与二进制 IMC 相比，FALCON 的随机表示显著降低了单比特翻转造成的误差影响。

  - 二进制 IMC 的 IoU 仅 0.64；
  - FALCON 的 IoU 为 0.89。
- FALCON 执行 256×256 闭合任务仅消耗约 **7.63 μJ**，相比冯·诺依曼基线估计可实现约 **10 倍能效提升**。
- 通过在源头上消除片外数据搬运、省去 RNG 电路，FALCON 能以微瓦级功耗实现高可靠内存算术。

## 7. 优点

- **高容错设计**：随机表示固有的噪声容忍性使其适合恶劣的工作环境。
- **无 RNG 开销**：确定性 LD 映射消除了传统 SC 中最耗资源的部分——随机数生成器和校准电路。
- **相关/不相关比特流可控**：通过选择 LD 模式，可精确调整流间相关性，从而支持多种算术操作。
- **完整算术套件**：在内存内部实现了乘、除、加减、极值等 ALU 功能，打破常规 SC-IMC 只能做简单逻辑或专用操作的局限。
- **低功耗与鲁棒电压缩放**：0.7V 下仍能正常工作，同时节省约 51% 的功耗。
- **纵深验证**：包含行为级误差分析、电路级 SPICE 验证、工艺蒙特卡洛分析以及真实图像处理应用验证。
- **真正意义的“内存内”计算**：从比特流生成到算术执行再到结果转换都直接在存储阵列中完成，数据迁移极少。

## 8. 不足与局限

- **随机计算固有精度限制**：即使采用确定性映射，SC 的精度仍依赖比特流长度；缩短长度以提高速度会迅速牺牲精度（例如 N=16 时高噪声下 MAE 可超过 15%）。

- **应用验证范围有限**：仅演示了形态学图像闭合，没有覆盖主流深度神经网络推理或时间序列传感分析等更复杂场景。
