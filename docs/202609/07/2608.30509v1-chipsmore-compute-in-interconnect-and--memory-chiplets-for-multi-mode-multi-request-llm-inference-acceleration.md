## 摘要
大语言模型(LLM)推理在适应模式、上下文长度和请求并发度方面表现出显著的差异性，这给在存内计算(CIM)加速器上维持高利用率、内存效率和可扩展性能带来了挑战。本文提出了CHIPSMORE，一种多模式和多请求LLM推理加速器，它集成了互连内计算和CIM，以支持在不同工作负载下的基座模式和低秩适应(LoRA)推理。CHIPSMORE采用由阻变RAM模拟存内计算(RRAM-ACIM)和静态RAM数字存内计算(SRAM-DCIM)组成的异构处理元件，这些元件通过可编程的PE间计算网络(IPCN)互连。一种可组合的分层键值(KV)内存方案根据工作负载需求动态分配路由器暂存存储器、SRAM-DCIM和嵌入式DRAM(eDRAM)资源，从而为长上下文和批量推理提供可扩展的支持。此外，一种非复制式多请求执行流水线利用请求级并行性，无需复制预训练权重，同时一种状态感知的资源重配置机制选择性地保留运行时状态并对不活动资源进行功耗门控，以提高能量效率。使用周期精确的软硬件协同仿真的评估表明，CHIPSMORE在不同模型大小、上下文长度和批大小下有效维持高吞吐量，同时保持良好的功耗扩展性。与Nvidia H100相比，CHIPSMORE在Mistral-7B推理上实现了高达2.38倍的吞吐量和27倍的能量效率提升，同时消除了多请求服务中的权重复制。

## Abstract
Large language model (LLM) inference exhibits substantial variability across adaptation modes, context lengths, and request concurrency, creating challenges for maintaining high utilization, memory efficiency, and scalable performance on compute-in-memory (CIM) accelerators. This paper presents CHIPSMORE, a multi-mode and multi-request LLM inference accelerator that integrates compute-in-interconnect and CIM to support both base-mode and low-rank adaptation (LoRA) inference under diverse workloads. CHIPSMORE employs heterogeneous processing elements consisting of resistive RAM analog compute-in-memory (RRAM-ACIM) and static RAM digital compute-in-memory (SRAM-DCIM) interconnected through a programmable Inter-PE computational network (IPCN). A composable hierarchical key-value (KV) memory scheme dynamically allocates router scratchpad, SRAM-DCIM, and embedded DRAM (eDRAM) resources according to workload requirements, enabling scalable support for long-context and batched inference. Furthermore, a non-replicated multi-request execution pipeline exploits request-level parallelism without duplicating pretrained weights, while a state-aware resource reconfiguration mechanism selectively retains runtime states and power-gates inactive resources to improve energy efficiency. Evaluation using cycle-accurate hardware-software co-simulation demonstrates that CHIPSMORE effectively sustains high throughput across varying model sizes, context lengths, and batch sizes while maintaining favorable power scaling. Compared with Nvidia H100, CHIPSMORE achieves up to $2.38\times$ higher throughput and $27\times$ higher energy efficiency on Mistral-7B inference while eliminating weight replication for multi-request serving.

# CHIPSMORE 论文详细总结

## 1. 核心问题与研究动机

大语言模型（LLM）推理场景存在多维差异性，导致传统 CIM 加速器难以全面适配：

- **适配模式差异**：推理既需要处理基座（Base）模型，也需要支持基于低秩适应（LoRA）的微调任务推理，这两种模式对权重存储提出了迥异的需求——预训练权重静态不变，适合非易失存内计算；LoRA 权重需频繁重配，适合可快速写入的 SRAM。
- **上下文长度差异**：KV-cache 容量随保留上下文长度和请求并发度线性增长（例如 Llama 3.2-1B 在 batch=4、16k 上下文时，KV 需求超过 120 MiB），单一层级存储难以覆盖容量跨度。
- **请求并发度差异**：解码阶段单请求吞吐低，需要多请求并发来提升硬件利用率；但现有方案普遍通过复制模型权重扩展吞吐，导致 RRAM 面积、功耗和成本随复制倍数近似线性增长。
- **现有研究缺口**：已有 CIM 加速器（PIM-GPT、AttAcc、NeuPIMs、CENT、H2-LLM、CHIME)通常只覆盖上述某一两个维度，无法在多模式、多上下文、多请求组合的宽操作空间内均维持高利用率与高能效（见表 I 的对比）。

## 2. 方法论

### 核心思想

CHIPSMORE 提出了一种**“面向负载的资源编排框架”**，从计算机制、存储层次和执行调度三个层面统一解决 LLM 推理的可变性问题。

### 技术架构

- **异构处理单元（PE）**：每个 PE 同时集成 RRAM-ACIM 宏单元（256×256，用于存储预训练权重）和 SRAM-DCIM 宏单元（256×64，用于 LoRA 矩阵或 KV 存储）。RRAM 负责持久性权重加速，SRAM 负责快速可重配参数加速。
- **PE 间可编程计算网络（IPCN）**：采用 2D Mesh 拓扑的计算路由器网络，支持三类操作：
  - **SMAC**：在 PE 内 CIM 宏上执行基于静态权重的矩阵-向量乘法（如 Linear 层、注意力投影）；
  - **DMAC**：在网络路由器内嵌计算宏上执行基于动态数据的 MAC 操作（如 Q·Kᵀ 注意力分数计算）；
  - **数据路由/广播**：在 PE 间传送中间张量。
- **IPCN 可编程控制**：包含网络程序存储器（NPM，双 Bank 交替加载）、网络主控制器（NMC）和配置协处理器（CC），配合 30 位 IPCN ISA 与软件编译器，可实现无中断运行时重配置。
- **芯片级扩展**：多个计算瓦片（Compute Tile）通过 UCIe 芯粒互连互连，形成可扩展的芯片组架构。

### 关键机制

- **持久性感知的计算划分**：静态预训练权重计算在 CIM 宏内执行，动态激活与中间张量计算在网络中完成。
- **统一空间映射**：采用 LEAP/PRIMAL 的空间映射方法，对预训练矩阵与 LoRA 矩阵采用相同的分块边界做几何切分，LoRA 计算结果可局部累加至基座输出。
- **可组合分层 KV 内存方案**：三层存储按需组合分配——路由器 Scratchpad（最邻近、最低延迟）→ SRAM-DCIM（第二层）→ eDRAM（大容量第三层）。Base 模式下 SRAM-DCIM 可腾给 KV；LoRA 模式下留给适配器权重，KV 溢出至 eDRAM。
- **非复制的多请求流水线（Non-Replicated Multi-Request Pipeline）**：每个 Transformer 层映射到唯一权重的计算瓦片簇上，多个请求以不同时间偏移注入流水线中不同的层，使多个请求同时占用不同层，共享同一份物理权重，无需复制预训练参数。
- **状态感知资源重配置**：计算完成后的瓦片簇根据留存状态类型决定断电范围——仅含 LoRA/KV 状态时只保留内存供电，关闭 IPCN 路由器和空闲计算模块；完全无状态的簇可整体断电。

### 关键公式

KV-cache 容量需求（同质批量场景）为：

C_KV = (B × T × L × 2 × N_KV × d_head × b_KV) / 8 bytes

其中 B 为批量、T 为保留上下文、L 为注意力层数、N_KV 为 K/V 头数、d_head 为头维度、b_KV 为 K/V 元素位宽。

## 6. 主要结论与发现

- **吞吐**：增大批量能显著改善吞吐（短上下文场景 Llama 3.2-1B 提升 3.91×、Mistral-7B 2.71×、Qwen3-14B 2.77×），但低于线性，受限于流水线填充/排空开销和共享资源竞争。
- **与 Nvidia H100 相比（Mistral-7B, batch=1）**：吞吐达 1112.5 vs 467.3 tokens/s（**2.38×**），能效达 36.24 vs 1.34 tokens/J（**27×**），且不复制权重；batch=4 时吞吐 1.8×、能效 19×。
- **LoRA 影响**：多数组装点 LoRA 吞吐约为 Base 的 0.84-0.99×；性能下降的主要来源是上 KV 缓存存储层级变化（SRAM-DCIM 被 LoRA 权重占用导致 KV 落入 eDRAM），而非 LoRA 矩阵计算本身。batch 增大和较长上下文能摊薄这种延迟损失。
- **流水线利用率**：提升批量能填充流水线层管，但利用率的量级受限于"批量÷层数"的比值；浅层模型（1B，16 层）更容易被填满，深层模型（7B, 32 层）利用率更低。
- **能效与功率**：IPCN/路由器子系统为最大功耗来源（功率占比 37.1%）；增大批量能同时提升吞吐和能效，而模型变大、上下文变长会降低能效；LoRA 模式的功率高于 Base 模式。
- **可扩展性**：UCIe 利用率最高不超过约 25%，片间互连不是系统瓶颈，说明数据被良好地局部化在了片内。
- **面积开销**：每计算瓦片的面积分解显示 eDRAM 以 37.1% 为最大开销，其次为 IPCN 路由子系统（32%），RRAM 与 SRAM 宏分别仅占 17.5% 和 8.9%。

## 7. 优点

- **问题定位精准**：识别了"适配模式、上下文长度、请求并发"三个相互耦合且现有工作未同时处理的维度，Motivation 清晰。
- **"持久性感知"划分计算**：按操作数的持久性将计算任务划分为 SMAC（CIM 宏内）和 DMAC（网络内），使计算资源与操作数特征匹配，构成了一个概念上简洁且新颖的架构原则。
- **高度灵活的存储管理**：同一套 SRAM-DCIM 资源在 Base 模式下承担 KV 存储、在 LoRA 模式下承担适配器权重，无额外硬件开销即支持两种模式，极大提升了资源复用。
- **非复制多请求流水线**：创造性利用了 Transformer 各层自带的天然串行结构来实现请求级并行，避免了对 RRAM 权重做多份复制的传统做法，从根本上解决了批量增加带来的存储/功耗代价。
- **状态感知电源门控**：通过区分"持久性权重、易失性适配参数、KV 状态"的不同留存要求，实现了亚线性的功率扩展，设计细腻。
- **工程完整性较好**：给出了 IPCN ISA、编译器设想、软硬件联合仿真流程、面积分解等，具备从架构到实现的完整闭环。

## 8. 不足与局限

- **缺乏真实芯片验证**：所有结论依赖周期精确模拟器逻辑综合；对比表中 H100、M4-Max 等是实测数据而 CHIPSMORE 行是仿真数据，现实性能（尤其模拟精度误差）可能使 27× 能效的差距在不同实现下明显缩水。
- **实验规模有限**：模型最大 14B、上下文最长 8k，未覆盖前沿 LLM（如 70B+）和超长上下文（32k/128k）场景；context 长度选择偏小，限制了图 2 所强调的 KV 扩展问题的说服力。
- **均质批量假设**：公式和实验假设同一批内请求上下文相同，真实服务场景中请求长度往往长短不一，本设计的动态内存分配面对异构混合长度批时的表现未验证。
- **缺少消融与敏感性分析**：对个别组件（IPCN in-network computing、eDRAM 刷新开销、分层 KV 切换的阈值）的贡献没有做进一步拆解验证；例如 eDRAM 的刷新机制对功耗和吞吐的实际影响未在结果中明确分离。
- **面积/功耗模型精度存疑**：只报告了功能级仿真的分项功耗占比，缺少在真实后端实现之后的互连时序/IR drop 等考虑，CIM 宏与 NoC 协同布局可行性未讨论。
- **应用限制**：不支持权重实时更新场景（预训练重训、持续学习）；也未讨论批内不同请求进入/离开（动态加入新请求）时硬件

继续补全上文：

……调度与资源回收的时机，所有评估均在批量请求同步进入、同步退出的假设下进行。真实在线服务中请求动态到达/离开引起的碎片化与重配置开销未被建模。此外，CHIPSMORE 仅考虑 LoRA 这类轻量微调适配，不支持需要全量权重更新的场景（如领域微调、持续学习），这会限制其在模型频繁迭代运营环境中的适用性。

## 9. 延伸思考与开放问题

- **同质批量假设的适用性边界**：真实的 LLM 推理服务器（如 vLLM、TensorRT-LLM）普遍采用连续批处理（continuous batching），批内请求的上下文长度差异极大。CHIPSMORE 的 KV 存储分配实验建立在“整批相同上下文”这一理想化设定上，而混合长度请求会改变层间流水线的负载均衡：长上下文请求会令某层的 KV 占用比其他层高出数倍，固定容量分配策略可能导致 head-of-line blocking。在异构批下，IPCN 路由器需具备按请求粒度动态调整存储映射的能力，论文尚未证明其数据流编译器能应对这种调度复杂度。
- **更长上下文与更大模型的容量压力**：模型中用于 KV 的公式可推算出，若上下文扩展到 32k/128k，即使是 1B 模型，单请求 KV 容量需求也会达到数十 MiB 量级。此时，SRAM-DCIM 与 eDRAM 的容量分配将出现根本性瓶颈——在 14B 模型的 LoRA 模式下，若上下文超过 32k，KV 将被完全挤入 eDRAM。届时每条请求的注意力 token 访问延迟是否仍然可控，论文的延迟分析（目前最长 8k）并没有给出清晰答案。
- **跨芯粒流水线的可扩展性**：当前设计以 4 芯粒、每芯粒 32×32 PE 网格为评估规模。若将模型扩展到 70B 甚至更大，需要将更多 Transformer 层跨芯粒放置。层间激活将频繁跨越 UCIe 链路，片间流量模型与当前“利用率仅 25%”的结论可能会发生质变。此外，流水线深度增加后，尾部气泡（tail bubble）的占比会被放大，批量-层数比进一步失衡，需要探索多模型并发或层内拆分等辅助策略。
- **CIM 精度与先进封装工艺的协同**：当前设计基于 7nm 逻辑工艺，但 RRAM 宏单元通常在成熟制程（如 28nm/40nm）下制造并集成到逻辑工艺中。跨工艺节点集成时，RRAM 单元良率与读写良率对推理精度的影响、DCIM 宏的 ADC 量化噪声在多层流水线中的累积效应等关键工程问题未被讨论。
- **软件栈全自动化的挑战**：文中对编译器只给出设计愿景（映射 MFU，实现数据流/控制流组合），但完整的编译链路还需解决：模型结构到流水线阶段的自动切分、CIM 宏非线性特性的软硬件协同容错、动态批量请求的在线映射决策等。这些都可能在真实部署时显著增加端到端编译时延。

## 10. 对研究者的启示

- **“持久性”是 CIM 架构设计的一等公民**：CHIPSMORE 最大的思想价值在于将计算操作数按“持久性”分类，而非按“矩阵乘法 vs 非矩阵乘法”分类。这一视角自然导出静态权重在非易失宏内、动态激活和数据在网络中、KV 在易失内存中的分工逻辑。它提示研究者：硬件架构可以在编译期根据数据的留存特征做结构映射，而不必拘泥于通用计算单元的范式。
- **内存层次结构也可以“按需组合”**：SRAM-DCIM 在 Base 模式充当 KV 缓存、在 LoRA 模式腾退给适配器参数的思路，是一种“软件调度驱动的异构内存虚拟化”。其示范意义在于：同一片物理存储不必静态定位其角色，而是由编译器根据工作负载的活跃状态动态适配。这种思想可被推广至其他多租户场景——例如同时运行不同微调版本的 LLM 服务时。
- **请求级流水线可替代权重复制路径**：现有 LLM 推理加速器普遍采用“复制模型“做数据并行，其隐性成本（面积、功耗、通信）通常被低估。CHIPSMORE 用层间流水线做时间偏移，让多个请求共享权重，以延迟换面积。这种权衡思路对后摩尔时代的芯片设计具有一般意义——在面积受限时，用时间复用替代空间复制往往能实现更高的资源效率。
- **实验中暴露出的仿真与实测鸿沟值得关注**：CHIPSMORE 与商业 GPU 能效对比中绝大多数来自仿真数据。对学术界而言，构建一个“真实硅验证 + 关键指标提取”的评估规范，或向社区开放 RTL 与模拟器工具链，可能比单独提升仿真精度对领域更有价值。

## 11. 总结

CHIPSMORE 针对 LLM 推理中“适配模式—上下文长度—请求并发”三维差异性问题，提出了一个基于 IPCN 异构可编程计算网络的 CIM 芯片组架构。其核心创意在于：用“持久性感知”原则统一了静态权重（RRAM-ACIM）、动态计算（网络内 DMAC）、适配参数与 KV（SRAM-DCIM）之间的分工与协作；并利用层间流水线实现了无需复制权重的请求级并行。实验在 1B～14B 模型、2k～8k 上下文、批量 1～4 的配置网格上，展示了相对 H100 最高 2.38× 吞吐与 27× 能效的优势，以及 LoRA 模式下性能几无折损的结论。论文保留了完善的可编程与可扩展机制，相关工作具备突出的系统完整性与时代洞察力。其可计算性结论仍需真实硅验证和更广泛负载（异构批量、长上下文、更大模型）的检验，但其提出的三类机制组合，为后续多合一推理加速器的研究提供了可借鉴的结构性范本。
