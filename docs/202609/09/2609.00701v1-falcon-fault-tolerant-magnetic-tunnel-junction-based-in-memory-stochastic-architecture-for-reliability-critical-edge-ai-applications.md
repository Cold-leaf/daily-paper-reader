## 摘要
随着神经推理和传感器边缘分析等现代数据密集型应用的扩展，它们日益遭遇冯·诺依曼存储墙，遭受过度的数据移动开销和严格的能量约束。利用新兴非易失性技术（如磁隧道结（MTJs））的存内计算（IMC）有望缓解这些瓶颈。然而，传统的基于二进制基数（radix）的IMC架构对工艺引起的波动具有过度的脆弱性，运行裕度受限，并受热噪声影响。为了弥合能量效率与计算可靠性之间的差距，本工作提出了FALCON，一种与随机计算（SC）相集成的容错、基于MTJ的存内算术架构。通过将数值编码为均匀比特流，SC自然地吸收局部软错误，并能够直接在存储阵列中使用高度紧凑的逻辑原语执行一系列基本算术操作。FALCON将确定性比特映射机制与可重构的存内逻辑（LIM）结构相结合，无需将数据传输到外部处理器或依赖面积和功耗均很大的随机数生成器。使用14纳米FinFET技术的实验结果验证了FALCON即使在激进电压缩放、严重工艺波动以及高达30%噪声注入下也能正确运行，使其成为可靠性关键边缘AI应用的稳健框架。我们还研究了FALCON在形态学闭运算这一现实噪声容忍图像处理案例中的正确功能。

## Abstract
As modern data-centric applications such as neural inference and sensor-edge analytics expand, they increasingly encounter the von Neumann memory wall, suffering from excessive data movement overhead and stringent energy constraints. In-Memory Computing (IMC) utilizing emerging non-volatile technologies, such as Magnetic Tunnel Junctions (MTJs), promises to mitigate these bottlenecks. However, conventional binary radix-based IMC architectures suffer from excessive vulnerability to process-induced variations, restricted operating margins, and thermal noise. To bridge the gap between energy efficiency and computational reliability, this work proposes FALCON, a fault-tolerant, MTJ-based in-memory arithmetic architecture integrated with Stochastic Computing (SC). By encoding numerical values into uniform bit-streams, SC naturally absorbs localized soft errors and enables the execution of an essential suite of arithmetic operations using highly compact logic primitives directly within the memory arrays. FALCON integrates a deterministic bit mapping mechanism with reconfigurable logic-in-memory (LIM) structures, eliminating the need to transfer data to external processors or area- and power-hungry random number generators. Experimental results using 14 nm FinFET technology validate the correct functionality of FALCON even under aggressive voltage scaling, severe process variation, and noise injection levels up to 30%, making it a robust framework for reliability-critical edge AI applications. We investigate the proper functionality of FALCON on morphological closing as a realistic noise-tolerant image processing case study.

## 1. 核心问题与整体含义（研究动机与背景）

随着神经推理、传感器边缘分析等数据密集型应用不断扩展，传统冯·诺依曼架构面临着日益严重的**存储墙**问题：大量数据在存储与计算单元之间搬运，带来了高昂的能耗和延迟。针对这一瓶颈，学术界提出了**存内计算**（In-Memory Computing，IMC）范式，利用新兴非易失性器件（如磁隧道结，MTJ）直接在存储阵列内执行计算，从而大幅减少数据移动开销。

然而，基于MTJ的IMC若沿用传统**二进制基数编码**，仍存在两大挑战：
- **可靠性脆弱**：二进制编码中每一位的权重不同，单比特翻转（soft error）可能造成巨大数值错误，且对工艺波动（process variation）、电压波动和热噪声极为敏感；
- **运行裕度受限**：器件级的非理想特性会在深亚微米工艺下进一步威胁计算正确性。

因此，核心问题是：**如何同时兼顾能效、计算灵活性与硬件可靠性**，构建适用于可靠性关键边缘AI的存内算术架构。FALCON 的核心思路是——将**随机计算**（Stochastic Computing，SC）与**MTJ存内计算**结合：SC以均匀比特流分布编码数值，单比特扰动对整体结果影响极小，天然具备软错误容忍能力；而MTJ器件则可直接在存储阵列内生成和操作这些比特流，从而在不牺牲能效的前提下获得高容错性。

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体架构

FALCON 由三大功能层组成（对应图2）：
1. **前端：确定性比特流生成单元**
   - 将常规二进制输入转换为随机计算所用的均匀比特流；
   - 采用**低差异（Low-Discrepancy，LD）确定性比特映射**方案，而非基于随机数发生器（RNG）的传统SC比特流生成方案。对 \(n\) 位二进制输入 \(X=(X_{n-1},\dots,X_0)\)，将每位 \(X_i\) 在长度 \(2^n\) 的比特流中按照特定LD模式复制 \(2^i\) 次并放置在预定义位置上。例如Pattern 1/2/3等不同映射模式（图2(a)）。
   - 该方案有三个优点：
     - 生成结果精确无采样误差；
     - 无需RNG电路，避免其面积/功耗开销；
     - 可通过选择相同或不同LD模式，**显式控制跨比特流相关性**：应用相同模式生成相关比特流（用于最小/最大/绝对减法等），应用不同模式生成不相关比特流（用于乘法等）。

2. **核心计算：可重构存内逻辑（LIM）算术单元**
   - 复用先前工作中提出的基于MTJ的LIM结构（每个单元含两枚MTJ作为输入器件，加一枚参考MTJ），在外围FinFET晶体管驱动下可重构实现AND、OR、XOR、MUX等逻辑原语。
   - 计算过程分两阶段：
     - **准备阶段（preparation）**：由比特流输入驱动的双向写电流将MTJ1和MTJ2编程为平行（低阻L）或反平行（高阻H）状态，配合参考MTJ3形成HH/HL/LH/LL四种阻值配置；
     - **评估阶段（evaluation）**：施加读电流，通过阻性分压在节点Y产生输出电压，经双端读出放大器（SA）产生互补逻辑输出（AND/NAND或OR/NOR），从而实现逻辑计算。
   - 结合LD模式的相关系数控制，单个LIM阵列可重构实现全部算术操作，无需将中间数据传输到外部ALU。支持的运算集包括：
     - **乘法**：对不相关比特流执行按位AND
     - **最小/最大**：对相关比特流执行AND/OR
     - **绝对减法**：对相关比特流执行XOR
     - **缩放加法/除法**：以控制比特流驱动2:1 MUX实现
   - 处理方式为比特流逐位串行，每周期一位。

3. **后端：比特流转二进制转换器**
   - 计算结果比特流可继续用于后续SC运算，或通过基于LIM的存内比特流-二进制转换器（图2(d)）恢复为加权二进制数。

## 6. 主要结论与发现

1. **架构可行性**：FALCON成功将随机计算与MTJ存内计算结合，在存储阵列内实现了一套完整的算术运算集——乘法、缩放加法、除法、绝对减法、最小、最大——无需外部ALU或RNG电路。
2. **高容错性**：凭借SC的分布式数值表示，FALCON在高达30%的比特级噪声注入下仍然维持可接受的精度。比特流长度越长，噪声容忍度越高。
3. **工艺波动鲁棒性**：在14nm FinFET器件参数±3σ、10%波动下，所有运算功能保持正确。
4. **电压鲁棒性和节能**：0.7V下仍能正确运行且节省约51%功耗，源于电压引起的MTJ读写电流变化只扰动个别比特，不改变比特流中1的统计比例。
5. **应用级可靠性**：形态学图像闭运算案例中，传统二进制IMC在30%噪声下严重退化（IoU仅0.64），FALCON仍恢复清晰连通结构（IoU为0.89）。
6. **能耗优势**：执行256×256形态学闭运算仅需7.63μJ，相比冯·诺依曼滑窗执行方案估算节能约10×（由于消除了片外数据搬运）。

## 7. 优点与亮点

1. **针对痛点的问题定位**：精准抓住了二进制IMC在软错误下的结构性弱点与SC天然容错之间的互补性，论证充分且有说服力（图1(a)的直观对比）。
2. **创新性的确定性比特映射**：用低差异确定性映射替代传统RNG或器件随机性的比特流生成方案。这不仅避免了SC通常最大的开销源（RNG），还带来了两个结构性优势：
   - 生成精度高、无采样波动；
   - 可显式控制比特流间的相关性，使得单一LIM逻辑资源可覆盖所有需要特定相关性的算术运算。
3. **"零额外数据搬运"的系统级设计**：三段式架构（二进制→比特流→存内计算→比特流→二进制）完整地集成于同一存储系统内，消除了冯·诺依曼架构中反复搬移数据的能耗与延迟。
4. **电路级验证扎实**：基于14nm FinFET和MTJ器件模型的HSPICE仿真覆盖瞬态行为、工艺波动、电压缩放三方面，提供了有力的物理实现可行性证据。
5. **多层次验证方法**：从逻辑级、电路级到应用级，形成了一个完整的"可靠性→电路性能→系统效果"验证链，可信度高。
6. **应用适切性强**：形态学图像处理属噪声容错的经典边缘任务，能有效放大FALCON的可靠性优势，验证了端到端价值。

## 8. 不足与局限

1. **噪声模型抽象化了物理过程**：表I中的误差注入是在逻辑门层面对输出比特做随机翻转，没有对MTJ写入失败率、读扰动、热噪声翻转率与电压降之间的具体物理映射进行建模，仿真结果不能完全精确反映真实错误率与器件参数的关系。
2. **与SOTA定量对比不足**：文中表III虽与十余种IMC架构进行了比较，但主要是定性描述而非基于统一仿真环境的规范化定量比较，无法直接量化FALCON相对其他SC-IMC（如SC-CRAM、SCRIMP、Stoch-IMC）的精确能效和延迟优势。且表III中延迟和能耗数据的可比口径不一致，部分数据来自不同文献和不同工艺节点。
3. **应用验证覆盖度有限**：只覆盖了形态学图像处理一个案例。论文声称面向"可靠关键的边缘AI应用"（神经推理、传感器分析），却未提供神经元感知、推理精度、端到端SC网络等实验，略显应用泛化不足。
4. **没有评估面积开销**：相对于二进制方案，SC需要更长的比特流和更多存储单元来编码相同精度。虽然论文报告了功耗节省，但未量化面积/单元数开销，这对芯片成本评估非常重要。
5. **延时劣势未定量对标**：SC以串行比特流处理数据，周期数O(N)随着位流长度线性增长（表II中周期数为N或N+0.5）。论文承认这一点，但没有与二进制IMC方案的端到端延迟做定量对比——对某些实时性强的边缘任务，吞吐量的下降可能无法仅由功耗与容错性弥补。
6. **能耗对比基准较简化**："能量相比冯·诺依曼基线节约约10×"的估算主要依据消除数据搬运的推算，没有详尽描述基线能耗模型细节。
7. **电压缩放物理机制解释简化**：仅用"比特流统计特性保持基本不变"来解释0.7V压降下的正确性，没有深入讨论电压下降可能对位流生成写入失败率上升的反作用边界。
